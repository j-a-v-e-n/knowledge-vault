# 金库分区（给 owner 看的一页）

你的 vault 从今天起有明确的三区，机器写权由代码强制：

| 区 | 有什么 | 机器 |
|---|---|---|
| **私人区** | MyBrain、Clippings、2-areas、3-resources、raw、attachments、1-projects（除下述飞地）、4-archive | **永不写**（读不设限；4-archive 机器只读它的高信号周报） |
| **公司区** | 0-工作台（唯一要你动手的面）、inbox（读完可删）、作战板.md、AI公司、1-projects/AI谋生/点子投递（你投点子的箱子，机器只挪进 processed/） | 读写 |
| **实战经验库** | [[实战经验库/README|AI公司/实战经验库]]——外面赢家怎么打 / 我们的高水位线 / 付过代价的教训 | 只增不删 |

**你不需要做任何事。** 枚举证明所有机器写点本来就都在公司区（零路径搬动，你的习惯全不变）。
新增三道防线，如实标各自强度：① python 写手过默认拒绝的分区闸 + 测试（代码强制）；
② 无人值守 LLM worker 的文件写入过 PreToolUse hook 闸（代码强制；但它的 Bash 命令写只有
粗正则拦截，非内核级——内核级 sandbox 属后续轮）；③ 动态卡名成分消毒（防拼路径越界）。
你自己的私人自动化（douyin-pipeline、claudian 凌晨班）不受影响、也不在这套闸的管辖内。

证据与细节：仓库 `campaign/VAULT-ZONES.md`（枚举全表）、`campaign/vault_zones.json`（清单）、
`campaign/tests/test_vaultzone.py`（含突变检查）。
