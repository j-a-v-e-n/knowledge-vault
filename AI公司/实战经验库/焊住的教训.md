# 焊住的教训

> 每条格式：**一句话教训** → 付了什么代价 → 防线现在焊在哪。按代价从大到小排。

## 1. 手搓的朴素验证器必漏——先调研现成方案，否则一行验证代码都不许写
- **代价**：坐实两次。note 验证只查「链接通不通」→ 放进了**编造的 note**；ship 闸只查「有没有输出」→ 放过了**空心功能**。两次都是拿"看着像验证"的东西当验证。
- **防线**：CLAUDE.md §1.7 升级为硬 blocker——写任何验证/检查/评估代码前，必须先产出带源调研（RAGAS / DeepEval / 执行式 eval…），没有调研 = 一行不许写；能直接用的直接用，没有就 fork 最接近的。
- **源**：`ai-architect/CLAUDE.md` §1.7。

## 2. 过程指标 ≠ 成——盲测干净/红队没打穿/验证器严，都不等于真实环境里出了想要的结果
- **代价**：多轮把"校准过了/关卡全过"当交付终点，owner 钉死后重写验收标准。
- **防线**：CLAUDE.md §1.5 最高验收标准 + VISION §2 + 战役纲领 §2——评成败只认接上真实环境后的真实结果；防作弊防得再严却不赚钱 = "特别诚实的废物"。
- **源**：`ai-architect/CLAUDE.md` §1.5；`VISION.md` §2。

## 3. 真正的反过拟合保证只有「前向未见数据」——in-sample 关卡再多也会被真优化器打穿
- **代价**：SLSQP 约束优化把全部 OOS 关卡打穿（Sharpe 3.71、DSR 0.9999 全过），前向 Sharpe 只有 0.05。随机搜索破不了的，真优化器能破。
- **防线**：G7 前向未见数据检查（t≥3 显著性，0/600 多测顶住）+ IsolatedGate 独立进程持 OOS。固定前向终会被自适应多测磨穿——生产要滚动/纸面前向。
- **源**：`architect/…/HARDENING-results.md`；STATUS 2026-06-27 第四轮。

## 4. 评审者不能是作者——同模型自查 N 遍只会重复同一个盲点
- **代价**：验证器 v0.1 两次同输入结果不同、关键模式漏判；多轮自评"看着都对"被 fresh-context 评审连续抓出真 bug（页脚不实声称、decision 正则吞标题、rollup 截断 22 vs 真值 34）。
- **防线**：战役纲领 §2.1 + §7——判决只认 fresh-context 独立子代理；事实型主张用代码判（零错误裁判），意见型才用不同源 ensemble；自查永远不算忠诚证据。
- **源**：`知识库/AI公司/战役纲领.md` §7；战役日志 Round 0.5 / Round 4。

## 5. 改 vault 路径最容易死在 orphaned watcher——迁路径前先枚举全部 writer/watcher/reader
- **代价**：历史上 watcher 盯着旧路径空转（卡永远等不来回词）。
- **防线**：战役纲领 §6 明令：先枚举全部读写方 → 双路守卫 → lockstep 迁移 → 每条 round-trip 证明后才切。W6（本轮）产出机器可读的枚举清单 `campaign/vault_zones.json` + conformance 测试。
- **源**：`知识库/AI公司/战役纲领.md` §6；本轮战役日志 Round 5。

## 6. 裸 `git pull --rebase` 会被持续追加的已跟踪日志文件挡死——两天推送全断都没人发现
- **代价**：origin ref 停在 07-08，两天 push 全部 non-fast-forward 被拒，box 侧零收货。
- **防线**：wrapper 先把脏树 sweep 成 commit（绝不 stash/丢弃）→ rebase → push 被拒重同步一次再试；新增 `--sync-only` 手动重同步入口。
- **源**：commit `2fae54d`；STATUS 2026-07-10。

- **防线**：raw 落盘（`.raw/.raw2`）+ 一次 format-repair 重试后才 fail-closed；fixture 测试钉住。
- **源**：commit `452898c`；STATUS 2026-07-10。

- **防线**：测试写路径全部 sandbox 化 + 生产台账重播种；同族防线=生产卡禁测结构闸（02:51 五连批事故后提案：test intent 必须带标，applier 拒绝无标写真卡）。

## 11. 订阅 OAuth 令牌做不了批量打分——单次正常、批量 429 到死，且对部分模型直接限死

- **防线**：批量打分走 metered API key；runner 带缓存/断点续跑/限速钩子（`MAST_PACE_SEC`）。
- **源**：STATUS 2026-06-25 卡点+根因定位。

## 12. 「必须用贵模型」的传闻要用封存集实测——Haiku 带锚点 prompt 与 Sonnet 在两个全新封存集上完全打平

- **防线**：自改循环用封存 held-out 集验真（对自改器不可改），结论进账本；翻默认开关留 owner（承重墙）。
- **源**：`calibration/fc3_selfimprove_results.json`；STATUS 2026-06-28 第七轮 ③。
