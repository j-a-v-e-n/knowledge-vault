# 个人网站 · 三个风格样张

内容完全相同（占位样文），只有"衣服"不同。每个站右上角有 🌙 暗色模式开关，暗色也各有性格，记得切一下。

## 1. 安静墨水 (quiet-ink)
🔗 https://javen-style-quiet-ink.vercel.app
暖纸底色 + 衬线字体 + 墨蓝链接 —— 像一本安静的书，写作优先、耐看十年。（参考 leerob.com 的气质）

## 2. 终端等宽 (mono-terminal)
🔗 https://javen-style-mono-terminal.vercel.app
全等宽代码字体 + 青色信号 —— 工程师的终端质感，"我是写代码的"一眼可见。（参考 antfu.me 的气质）

## 3. 大胆编辑部 (editorial-bold)
🔗 https://javen-style-editorial-bold.vercel.app
画廊灰底 + 几何无衬线标题 + 电光蓝（暗色模式是荧光黄绿）—— 自信张扬，设计感最强。（参考 rauno.me 的气质）
