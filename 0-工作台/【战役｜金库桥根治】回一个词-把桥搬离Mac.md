# 金库桥根治：把桥搬离 Mac（一键卡）

**现状（已做完的）**：你合盖睡觉时 Mac 上任何程序都跑不了——这是物理下限，软件绕不过。本轮已把影响压到最小：①开盖即刻补跑同步（launchd 换 StartCalendarInterval，实测睡醒真补跑）；②告警学会了扣除睡眠时间（整夜合盖不再每早误报，白天真故障照样秒告警）。**但睡眠中桥仍是断的**：box 夜里产出的东西，要等你开盖才进金库。

**根治 = 让不睡觉的机器直接碰金库**（调研全文带源：repo scratchpad bridge-research.md，A/B 栏逐条比较）：

## B1（推荐 ★★★★★）：box 用 rclone 直连 Google Drive，Mac 彻底退出这条链
- **大白话**：金库住在 Google Drive；现在只有你的 Mac 有 Drive。给 box 也配一把"只属于这个用途"的 Drive 钥匙（rclone 的 OAuth token），box 24/7 直接同步，你的 Mac 睡不睡都无所谓。
- **你要做的（一次性，约 15 分钟）**：① Google Cloud Console 免费建一个 OAuth 客户端（rclone 官方文档说用哪个 Google 账号都行、不需要管理员）；② 浏览器点一次"同意"授权；③ 把生成的 token 交给机器放到 box。花费 $0。
- **诚实风险**：`@ucsd.edu` 是学校 Workspace，管理员**可能**禁自建 OAuth 应用——这是唯一硬门槛，5 分钟一试便知；被挡的话换你个人 Gmail 持有金库或申请豁免。双向同步不用官方声明有丢数据风险的 bisync 裸跑，用 rclone copy 分方向 + 沿用信使已验证的单作者仲裁逻辑。

## B2（备选 ★★★★）：GitHub Actions 云端定时同步——连 box 都不依赖
- 同样的 token 存 GitHub secret，云端每 30 分钟跑一次。完全不依赖任何自家机器；缺点是 Actions 定时是尽力而为（常迟 5-30 分钟），新鲜度不如 B1。免费额度内。
