# 0-工作台 —— 只放等你动手的事

这里的每一张卡都在等你的动作；办完就消失。**先看 [[00-面板]]**——一张表列出所有卡、
每张等你干什么、等了几天（机器每 30 分钟自动重写，最久的排最上）。

## 卡片标准（2026-07-11 起，焊进所有写卡代码）

- **文件名**：`【项目｜环节】动作短语.md`——不点开也知道是谁的事、要你干什么。
- **前三行**：① `**这是什么**：`哪个项目的哪一步；② `**需要你做什么**：`一句话动作；
  ③ `**不办会怎样**：`后果/截止。

## 机器规则（2026-07-08 上线）

- **有 watcher 的卡**（发布审批 / 提案裁决 / 激活）：你在卡里回一个词，机器 30 分钟内
  执行并把卡自动清进 `done/`。
- **没 watcher 的卡**（一次性待办）：③ 行写着「办完 → 拖进 done/」，你拖。
- **`done/` 每天由 ops 巡检（10:15）归档**到仓库 `ops/workbench-done/`，面板永远只剩没办的事。
- 运维告警卡修好后**不用动**——巡检确认恢复自动清。
- FYI 报告（读完删）继续走 `inbox/`，不进这里。

本 README 和 00-面板 不是卡；watcher 走状态文件定位卡，唯一按文件名扫描的是
`运维告警-*`，不会误伤。
