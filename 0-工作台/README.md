# 0-工作台 —— 只放等你动手的事

这里的每一张卡都在等你的动作；办完就消失。机器规则（2026-07-08 上线）：

- **卡首行「需要你做什么」**一句话说清动作；`[[wiki链接]]` 直接跳到相关文件。
- **有 watcher 的卡**（发布审批 / 改进提案）：你在卡里回一个词，机器 30 分钟内执行并把卡自动清进 `done/`。
- **没 watcher 的卡**（一次性待办 / 提案类）：卡上写着「办完 → 拖进 done/」，你拖。
- **`done/` 每天由 ops 巡检（10:15）归档**到仓库 `ops/workbench-done/`，面板永远只剩没办的事。
- 运维告警卡修好后**不用动**——巡检确认恢复自动清。
- FYI 报告（读完删）继续走 `inbox/`，不进这里。

本 README 不是卡；watcher 走状态文件定位卡，唯一按文件名扫描的是 `运维告警-*`，不会误伤。
