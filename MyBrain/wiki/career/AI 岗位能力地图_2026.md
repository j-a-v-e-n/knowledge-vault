# AI 岗位能力地图 2026

> **核心洞见：新毕业生进入 AI 的最优 path 不再是 ML PhD → MLE，而是 SDE 底子 + 一个垂直能力（agent / RAG / eval / red team / inference），由垂直能力打开门。模型已商品化，部署 + 评估 + 安全才是稀缺。**

---

## 1. 整体大图 — 2026 AI 求职市场结构

### 宏观数字 (confidence: high)

- **2023–2025 间 LinkedIn 在美国新增 639,000 个 AI-related job posting**，其中 75,000 为 AI Engineer 专职岗位 [source: 01_current_market.md §0]
- **AI Engineer 连续两年（2024-2025）位列 LinkedIn Jobs on the Rise #1** [source: 01_current_market.md §0; 03_emerging_roles.md]
- **Q1 2025 AI-related job openings 35,445，YoY +25.2%** [source: 01_current_market.md §0]
- **"Agentic AI" 提及量 2023→2024 +986%** [source: 01_current_market.md §0]
- **Forward Deployed Engineer 岗位 2025-01 → 2025-09 +800%** [source: 01_current_market.md §0; 03_emerging_roles.md]
- **AI Specialist vs non-AI base salary premium**（2025）：Entry 6.2%，Mid 11.9%，Senior 14.2%，**Staff 18.7%** (up from 15.8% in 2024) [source: 01_current_market.md §0]

### 市场结构三大 shift (confidence: high)

1. **模型商品化，部署 = 护城河** — Frontier labs (OpenAI / Anthropic) 的 hiring 从 2023 纯研究转向 2024-2025 commercial deployment + 硬件特化。Anthropic go-to-market 岗位从 17% → 31%，OpenAI 从 18% → 28% [source: 02_frontier_labs.md §3]

2. **Agent 浪潮催生新 role title** — 2024 LangGraph / AutoGen / CrewAI 成熟后，"Agentic AI Engineer" 从零到 9,145 个岗位（Indeed 数据），LangChain 出现在 34.3% agent listings [source: 03_emerging_roles.md]

3. **初级岗位双杀：传统 SDE + ML 通用岗萎缩** — Microsoft 调查显示 40% 近期裁员打击 developer；纯 ML Engineer（无 LLM/agent 技能）岗位 Q2→Q3 2024 -67%；entry-level AI premium 从 10.7% (2024) 压缩到 6.2% (2025) [source: 01_current_market.md §4; 04_dying_commoditizing.md §4]

### "岛屿效应"(confidence: high)

AI 角色是 2025 tech hiring "big freeze" 中的扩张岛屿——整体 tech hiring 降至 2010 水平，但 AI Engineer / FDE / Agentic Engineer / AI Safety 等垂直角色逆势增长。**BLS 预测 Data Scientist +34% (2024-2034)，Computer & Info Research Scientist +20%，远超 tech 平均** [source: 01_current_market.md §5]

### Q1 详解 (重投资区 — 今年集中投入)

**Inference / Serving Engineer** (confidence: high)
- **为什么高寿命**：GPU 是 AI 公司最大 OPEX，省 30% 推理成本就是几千万 ARR；vLLM / Triton / TensorRT-LLM 工具存在但 enterprise 复杂场景仍需要人深度定制 [source: 03_emerging_roles.md §5; 04_dying_commoditizing.md §11]
- **为什么 Javen-fit**：ECE 背景 + ECE 175A/175B 工程课 + signal processing 底子 = 系统编程 + GPU 理解天然适合
- **Entry path**：CS/ECE/EE 本科 + CUDA/系统课 + 写 vLLM PR → 申 Together AI / Anyscale / CoreWeave
- **Salary**：CoreWeave Senior II $165K–$242K base；NVIDIA AI DevOps Mgr $224K–$356K [source: 03_emerging_roles.md §5]

**AI Safety / Red Team Engineer** (confidence: high)
- **为什么高寿命**：监管驱动（EU AI Act、白宫 EO 14110）让每个 high-stakes AI deployment 被合规要求做 red team [source: 03_emerging_roles.md §2]
- **为什么 Javen-fit**：门槛低于其他 AI safety role——CTF 经验 + jailbreak research > YOE；ECE 数学 + 认知科学（COGS117）背景 + adversarial thinking 完美 match
- **Entry path**：CS/Math/Physics 本科 + 公开 jailbreak research / Hugging Face eval contribution → 申 10a Labs / Scale AI entry-level red team
- **Salary**：Entry-level $130K–$220K；Anthropic/OpenAI alignment engineer TC $300K–$600K [source: 03_emerging_roles.md §2]

**LLM Eval Engineer** (confidence: high)
- **为什么高寿命**：Eval 是 production AI 的瓶颈；被自动化 eval 工具（Braintrust、Langfuse）部分替代，但 enterprise / safety-critical 仍需人 [source: 03_emerging_roles.md §6; 04_dying_commoditizing.md 预测]
- **为什么 Javen-fit**：**COGS117 数据分析 + ECE 数学底子 + 175A/B 工程能力 = 完美 match**；statistics / cognitive science / ML 背景皆可
- **Entry path**：本科 + 写一个 open-source eval suite（建议：做一个 cognitive-task LLM benchmark 接 COGS117）→ 申 Scale AI / Surge / YC Dynamo AI
- **Salary**：LLM Engineer wide range $124K–$206K；顶级 senior $200K–$312K [source: 03_emerging_roles.md §6]

**Forward Deployed Engineer** (confidence: high; 12-24mo 主流化但不商品化)
- **为什么高寿命**：模型商品化让 deployment = moat；a16z 定性"services-led growth is the new moat" [source: 02_frontier_labs.md §1]
- **为什么 Javen-fit（但需 1-2 yr detour）**：需要 production code 经验 + customer-facing 能力；Javen ECE 284 LLM 项目 + 175B Diffusion 项目 = 技术底子，但缺 customer-facing；**需要先做 1-2 年 SDE 补 soft skill**
- **Entry path**：先做 1-2 年 SDE → 申 Anthropic / OpenAI / Scale AI / Glean Applied AI Engineer
- **Salary**：OpenAI/Anthropic mid-senior TC $350K–$550K，staff 级 $630K+ [source: 01_current_market.md §2; 02_frontier_labs.md §1; 03_emerging_roles.md §1]

### Q2 详解 (选修区 — 学了能加分但 ROI 低)

**Mech Interp Researcher** — 稀缺且高薪（$315K–$850K base at Anthropic），但需 PhD path；Javen 本科 + 即将 MS 不适合 detour 去读 PhD（除非真热爱） [source: 03_emerging_roles.md §8]

**AI Product Manager** — 60% 非 CS 背景 OK，但通常需要先做 2 年传统 PM；Javen ECE 技术底子 + 工程导向 ≠ PM career path [source: 03_emerging_roles.md §4]

### Q3 详解 (当前能用区 — 能 land first job 但不长期投资)

**Agentic AI Engineer** (confidence: medium-high; 框架会换代)
- **为什么当前能用**：最适合新毕业生立刻申请；自学 LangChain/LangGraph 1 个月 + 一个 portfolio agent project，直接申 mid-tier AI startup [source: 03_emerging_roles.md §3]
- **为什么低寿命**：会重演 LangChain 之路——vanilla framework coding 会被更上层的 "Agent SDK by Anthropic / OpenAI" 取代（OpenAI 已发 Agents SDK）；LangChain 社区 2024-2025 抱怨频繁 breaking change + 过度抽象 [source: 04_dying_commoditizing.md §3, 预测 §1]
- **Javen 怎么用**：Vault `automation/` 已经是 multi-agent 系统 sandbox，把它当 portfolio；**用它 land first job，但不长期押注单一框架**
- **Salary**：Senior median max $275K；framework-agnostic 比 LangChain-specific 高 $80K [source: 03_emerging_roles.md §3]

**RAG / Knowledge Engineer** (confidence: medium; 被工具压缩)
- **为什么当前能用**：大量岗位（9,145 LLM 岗位里很多 implicit RAG）[source: 03_emerging_roles.md §7]
- **为什么低寿命**：OpenAI / Anthropic 内建 RAG 工具（File search、Project knowledge）+ Contextual Retrieval 会吃掉简单 RAG 需求；剩下复杂 enterprise / multi-source / 实时 RAG 仍需人，但 role 会改名为 "AI Data Engineer" [source: 04_dying_commoditizing.md §2; 03_emerging_roles.md §7]
- **Javen 怎么用**：传统 Data Engineer 转型路径；新毕业生可用 CS 本科 + 一个 RAG 项目 land startup，但**不把它当长期技能树**

### Q4 详解 (绕开区 — dying 又跟 Javen 背景无关)

**Prompt Engineer 1.0** — Fortune 2025-05 定性 "$200K role obsolete"；Microsoft Work Trend Index 调查里排倒数第二；standalone title 2024-2026 下降约 30% [source: 04_dying_commoditizing.md §1]

**Pure ML Engineer (无 LLM)** — Q2→Q3 2024 岗位 -67%；技能被 rebrand 成 AI Engineer / LLM Engineer，不是消失，是要求加 RAG / agent / eval / prompt [source: 04_dying_commoditizing.md §4]

**Data labeling 操作员** — Scale AI 2025-07 裁 14% + 解约 500 承包商；低端 crowdsource 已死透，剩下 expert labeling (医生、律师、PhD) [source: 04_dying_commoditizing.md §5]

## 3. **3-Tier 排序: Javen 的 Capability Investment 优先级**

### Tier 1 (今年集中投入，高 ROI)

#### **#1 — LLM Eval / Benchmark Design** (confidence: high)

**是什么**：设计 benchmark、自动 eval、人工 eval pipeline、continuous eval in production；与传统 QA 区别是测试 stochastic + subjective output，要设计 LLM-as-judge、reference-free eval、多 turn eval

**怎么练**：
- **Portfolio project（立刻做）**：基于 COGS117 数据分析背景，做一个 **cognitive-task LLM benchmark**（例：reasoning / memory / context-switch 测试 suite，接 COGS117 认知建模）
- **Open-source contribution**：给 OpenAI Evals 库 / Anthropic eval framework / HuggingFace Evaluate 贡献 domain-specific eval（医疗信号 / embedded AI eval）
- **Skills 补充**：statistics（power analysis、confidence interval）+ Python + experiment design

**Javen 现有 portfolio 怎么 bridge**：
- ECE 284 LLM-for-PPG 项目 → **写一篇 "How to Evaluate LLM Medical Signal Prediction" blog post**，定义 domain-specific metrics（accuracy on physiological outlier / hallucination rate on sparse data）
- COGS117 数据分析 + ECE 数学 → **直接匹配 eval engineer 的 statistics 要求**

**投入产出比**：
- **Entry-level 友好**（statistics / cognitive science / ML 背景皆可）
- **不会被 12-24mo 工具化完全取代**（enterprise / safety-critical 仍需人）
- **Salary $124K–$312K** [source: 03_emerging_roles.md §6]

#### **#2 — Inference / Serving Optimization** (confidence: high)

**是什么**：优化 LLM 推理成本——KV cache、continuous batching、speculative decoding、quantization、multi-GPU scheduling；与传统 backend 区别是必须懂 GPU / CUDA / 内存层次

**怎么练**：
- **Portfolio project（需 3-6 个月投入）**：
  - 给 vLLM 贡献 PR（例：优化某个 edge case 的 batch scheduling）
  - 或写一个 "vLLM vs TensorRT-LLM benchmark on LLaMA 3" 技术 blog（含 latency / throughput / cost 分析）
- **Skills 补充**：vLLM、Triton、TensorRT-LLM、CUDA 基础（可上 NVIDIA Deep Learning Institute 免费课）、PyTorch

**Javen 现有 portfolio 怎么 bridge**：
- **ECE 背景 + ECE 175A/175B 工程课**天然适合系统编程
- ECE 284 LLM 项目 → **写一篇 "Optimizing LLM Inference for Medical Signal Tasks" analysis**（医疗设备 edge deployment 对 latency / power 敏感，可 angle 成 edge AI 优化）

**投入产出比**：
- **门槛较高**（需系统 + GPU 基础），**竞争少**
- **高薪稳定**（$165K–$356K base）+ GPU 是 AI 公司最大 OPEX，永远缺人
- **长期不会商品化**（enterprise / edge AI 复杂场景需要深度定制）

#### **#3 — AI Safety / Red Team** (confidence: high)

**是什么**：测试模型失败模式、jailbreak、bias、unsafe outputs；与 cybersecurity 区别是攻击 **模型的认知**——prompt injection、jailbreak、deceptive alignment

**怎么练**：
- **Portfolio project（立刻做）**：
  - 发一篇 jailbreak research（例：找 Claude / GPT-4 的某类新 prompt injection）
  - 给 HuggingFace 某 eval dataset 贡献 adversarial examples
- **Skills 补充**：ML 基础 + adversarial thinking + RLHF / Constitutional AI 理解 + 能写 eval；published research / CTF 经验比 YOE 更重要

**Javen 现有 portfolio 怎么 bridge**：
- COGS117 认知科学 + ECE 数学 → **写一篇 "Cognitive Biases in LLM Reasoning" red team report**（测试 LLM 在哪些认知任务上 fail）
- ECE 284 医疗 LLM 项目 → **写一篇 "Medical LLM Safety: Hallucination on Sparse Physiological Data" 分析**（医疗 high-stakes 场景 = safety 天然角度）

**投入产出比**：
- **Entry-level 友好**（门槛低于其他 AI safety role）
- **监管驱动增长**（EU AI Act / 白宫 EO 强制要求 red team）
- **Salary $130K–$220K entry；$300K–$600K at frontier labs** [source: 03_emerging_roles.md §2]

## 5. Frontier Scarcity Signal — 哪些能力稀缺到 Frontier Lab 抢

按 frontier labs (Anthropic / OpenAI / DeepMind / xAI) 招聘强度 + A2/A3 综合 (confidence: high)

| Rank | Scarce capability | Why scarce | Frontier-lab evidence | Javen-fit |
|---|---|---|---|---|
| **1** | **Forward deployment + customer integration** | 模型商品化 → 部署 = moat | Anthropic / OpenAI FDE 全 +50 人扩张 [source: 02_frontier_labs.md §1] | 🟡 需 1-2yr detour 补 customer-facing |
| **2** | **Custom silicon / on-device ML** | Compute 效率 + 硬件协同 = frontier moat | OpenAI 21 roles consumer device; DeepMind XR [source: 02_frontier_labs.md §2] | ✅ ECE 硬件 + 嵌入式背景完美 match |
| **3** | **Evaluation + benchmarking infrastructure** | Eval = arms race; 无法 verify 新 SOTA | OpenAI "Research Engineer, Frontier Evals" 显性招 [source: 02_frontier_labs.md §3] | ✅ COGS117 + ECE 数学完美 match |
| **4** | **Safety + alignment engineering** | RLHF / red-team / mech interp 稀缺 | Anthropic 招但 opacity 高；DeepMind "Responsibility" roles [source: 02_frontier_labs.md §4] | ✅ Red team entry path 可行 |

## 6. ⚠️ 矛盾点 + 不确定

### 矛盾 #1：Agentic AI Engineer 寿命判断不一致 (confidence: medium)

- **A3 (emerging_roles)**: "Agentic AI Engineer 是 2024 新兴 role，9,145 岗位，主流化 + 分裂"

- **解读**：两者不矛盾——**role title 在涨，但 framework-specific 技能（LangChain / LangGraph）会商品化**。正确策略：**用 agentic skill land first job，但不押注单一框架**，学 framework-agnostic agent design

### 矛盾 #2：RAG 是否 obsolete (confidence: medium)

- **A4 (dying_commoditizing) §2**: "Naive RAG 已死，long-context + agentic retrieval 是新基线"
- **A3 (emerging_roles) §7**: "RAG Engineer 9,145 岗位，被工具压缩但 enterprise 仍需人"
- **解读**：**Naive RAG (fixed chunk + vector DB) 已商品化；Agentic RAG + late chunking 仍是 active skill**。正确策略：**不把 naive RAG 当核心技能，但学 agentic retrieval + contextual retrieval**

### 矛盾 #3：xAI data labeling transparency paradox (confidence: low)

- **A2 (frontier_labs) §4**: "xAI 公开招 27 human data labeling roles，Anthropic / DeepMind 几乎不公开"

- **影响 Javen**: 无——data labeling 操作员在 dying 清单里，不管 xAI 策略如何都不该投入

### 不确定 #1：Entry-level AI premium 会否继续压缩 (confidence: medium)

### 不确定 #2：Frontier labs safety hiring opacity (confidence: low)

- **影响 Javen**: Safety / red team entry-level 岗位可能比公开数据多，值得主动 reach out（LinkedIn / 内推）
