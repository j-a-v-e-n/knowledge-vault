## 0. 约束（US citizen, 简化版）

- ✅ 所有合法 US work / contractor / freelance 都可做
- ✅ 海外平台（中国 / 加拿大 / 欧洲）接单付到任意账户合法
- ✅ 自雇 / 注册 LLC / SaaS 全开
- ⚠️ **税务**: contractor income 走 1099-NEC，self-employment tax 15.3% + federal income tax；任何渠道收入 $400+ 触发 self-employment tax filing
- ⚠️ **健康保险**: 若不在 UCSD SHIP 或 parent insurance，自购 cost $200-400/mo
- ⚠️ **机会成本**: 10 周窗口；暑期最后 2 周（8 月中-底）切到秋招 mode—Anduril / Qualcomm / Anthropic FDE / OpenAI 等 fall 周期开

**真实时间窗**: 6 月初到 8 月中 ≈ 10 周。但任何 platform onboarding 需要 2-4 周（application → skill test → first project），实际**active earning 窗口 ≈ 6-7 周**。

## 1. 渠道分级地图（按 risk-adjusted ROI 排）

### 🟢 Tier 1: 高时薪 ML/AI contractor（US citizen 主推, time-to-first-$ 短）

#### 1.1 Mercor（ML/AI talent marketplace, 推荐 #1）

- **URL**: [talent.docs.mercor.com](https://talent.docs.mercor.com/)
- **真实时薪**: $50-150/hr ML 类（avg $85, top $200，verified Glassdoor / Mercor docs）
- **现实 10 周收入**: $7k-$25k（30 hr/wk × $85 × 8 active 周）
- **技能匹配**: HIGH — ECE 175B (Diffusion) + 284 (LLM-PPG) + 148 (Robotics) 直接 fit Mercor 的 ML domain expert pool
- **Time to first $**: 3-4 周（apply → skills test → onboarding → first project）
- **入门**:
  1. mercor.com 注册 + 完成 profile（resume + GitHub + project portfolio）
  2. 通过 skills test（ML/Python coding）
  3. Interview with sourcing team
  4. 装 Insightful 时间追踪工具
  5. 接第一个 project
- **红旗**: 工时不稳定（不保证每周 40 小时）；项目质量参差不齐
- **portfolio bonus**: contractor 经验写简历 OK，但不如学术 / 大厂 internship 信号强

#### 1.2 Toptal（top 3% freelance network, 推荐 #2）

- **URL**: [toptal.com/freelance-jobs](https://www.toptal.com/freelance-jobs)
- **真实时薪**: senior ML $80-150/hr; AI/ML lead $120-200/hr（verified Levels.fyi / Arc.dev）
- **现实 10 周收入**: $10k-$30k（30 hr/wk × $100 × 7 active 周）
- **技能匹配**: HIGH — Toptal 经常有 ML/AI engineer 需求
- **Time to first $**: 4-6 周（application gate 严格：language test + technical test + live coding + trial project; 通过率 3%）
- **入门**:
  1. toptal.com 注册 + apply
  2. 通过 5 阶段筛选（English screen → in-depth test → live coding → test project → screen call）
  3. 加入 talent pool → 接 client match
- **红旗**: application 时间投入大（2-3 周准备）；若 fail 6 个月不能 reapply
- **portfolio bonus**: "Toptal certified" 是简历强信号

#### 1.3 Scale AI Outlier（coding/AI reviewer track only）

- **URL**: [outlier.ai/faq](https://outlier.ai/faq)
- **真实时薪**: coder $30-56/hr，AI reviewer $65/hr（generalist writing $15-25 不推荐做）
- **现实 10 周收入**: $5k-$15k
- **技能匹配**: MID-HIGH — coding 任务 ECE 直接用
- **Time to first $**: 2-3 周（qualification test → role assignment → task bidding）
- **入门**:
  1. outlier.ai 注册 + skills screening
  2. Domain-specific qualification test（选 coding / AI reviewer 不选 writing）
  3. 接 task
- **红旗**: 任务 supply 不稳；contractor classification 复杂

#### 1.4 Codementor（1-on-1 AI mentoring, 高时薪 niche）

- **URL**: [codementor.io](https://codementor.io)
- **真实时薪**: AI expert $80-250/hr，self-set rate；新 mentor 建议 $50-80/hr 起（verified PayScale）
- **现实 10 周收入**: $5k-$20k（讲求 client 流量，不一定持续）
- **技能匹配**: HIGH — 1-on-1 mentoring 卖你的 ECE/ML expertise
- **Time to first $**: 1-2 周（profile approval 快）
- **入门**:
  1. codementor.io 注册 + 写 profile（list ECE 项目 + GitHub link）
  2. 设 hourly rate（建议 $80 起）
  3. 等 client request，或主动 reach out
- **红旗**: client 流量不稳定；定 rate 太高接不到单，太低不值得

### 🟡 Tier 2: 长期 portfolio + 中等 ROI（推荐 in parallel 做 1-2 个）

#### 2.1 UCSD Faculty RA

- **真实时薪**: $18-25/hr undergrad
- **现实 10 周收入**: $7k-$10k（40 hr/wk × $20 × 10 wk = $8k）
- **技能匹配**: HIGH — 跟你 ECE 项目对口
- **Time to first $**: 2-4 周
- **入门**:
  1. 列 5-8 个 ECE/CSE/CogSci faculty target list（signal processing / ML / robotics / LLM 方向）
  2. 写个性化邮件（50-100 words + GitHub link + 项目说明）
  3. 一次性投出去
- **核心价值**: paper authorship + 学术 reference + 簡歷质量信号——比纯 contractor 钱更 valuable for 秋招
- **红旗**: 比 Mercor 时薪低（4×），但 portfolio + reference 价值高

#### 2.2 Kaggle Competition

- **真实收入**: 单 comp $500-$50k 池；典型 top 10% $500-$5k（[Kaggle Competitions](https://www.kaggle.com/competitions)）。10 周 newbie serious = $1k-$5k；strong placer = $5k-$15k
- **技能匹配**: HIGH
- **Time to first $**: 4-12 周（首次 placing）
- **核心价值**: Kaggle medal 是 ML 简历强信号
- **红旗**: 高竞争 + 高随机性

#### 2.3 AI Hackathon Blitz

- **真实收入**: 单 event $1k-$50k 池（[MLH 2026](https://www.mlh.com/seasons/2026/events) / Devpost / Lablab.ai）。10 周做 2-3 个 event + top 5 现实 = $3k-$10k
- **技能匹配**: HIGH（LLM hackathon 满天飞，Anthropic / OpenAI / Cohere 常赞助）
- **Time to first $**: 3-7 天/event
- **核心价值**: 加简历项目 + LinkedIn 曝光
- **红旗**: 周末 high-intensity，会累

### 🟠 Tier 3: 高启动成本 / 长滞后回报

#### 3.1 Algora OSS Bounty

- **真实收入**: 单 bounty $50-$2k（[Algora](https://algora.io/bounties/)）, 10 周 $1k-$3k filler
- 适合 filler 副业；不主推

#### 3.2 自研产品（Chrome extension / SaaS / GPT app）

- **真实收入**: Indie Hackers 中位数 $100-$1k/mo（成功案例 outlier，median 很低）
- **Time to revenue**: 3-6 个月 minimum
- **判断**: 10 周不够 build + 推广 + monetize；2026 fall 之后副业项目可考虑

#### 3.3 海外平台接单（字节 / 阿里 / 猪八戒 / 程序员客栈）

- **真实收入**: CNY 100-500/hr (~$15-70 USD)
- **US citizen 合法**: ✓ 完全可做
- **判断**: 时薪不如 Mercor / Toptal，但若有中文社区资源 / 个人关系 → 可作为副线

## 2. 推荐 Strategy

### 主力组合 A — Max income (推荐 if 目标 $20k+)

```
70% time → Mercor or Toptal (高时薪 ML contractor)
20% time → AI Hackathon weekend blitz (portfolio + $3-10k)
10% time → Kaggle (background, 1 strong comp 试水)
```

**预期**: $15k-$35k 现实区间；upside $40k+（top performer）
**风险**: 缺学术 portfolio；秋招 narrative 弱

### 主力组合 B — Balanced (推荐 if 目标 $10k-$15k + portfolio)

```
50% time → UCSD Faculty RA ($8k 兜底 + paper)
30% time → Mercor part-time (额外 $5k-10k)
20% time → Hackathon weekend
```

**预期**: $13k-$22k + paper authorship + 学术 reference
**风险**: Faculty RA 拿不到则 plan 崩

### 主力组合 C — Conservative + 简历 (推荐 if 秋招 priority)

```
60% time → UCSD Faculty RA ($8k + paper + reference)
25% time → Kaggle 主攻 (1 comp full effort)
15% time → Hackathon 周末
```

**预期**: $9k-$15k + paper + Kaggle medal
**风险**: 收入最低，但秋招信号最强
