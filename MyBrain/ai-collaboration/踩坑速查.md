## 通用坑（跨项目复用率高，优先看）
═══════════════════════════════════════════════
### Kaggle
- CLI push 时 dataset 挂载点是 /kaggle/input/datasets/<owner>/<slug>/
  （不是网页版的 /kaggle/input/<slug>/）。用 glob.glob("/kaggle/input/**/目标", recursive=True) 自动找最稳
- private dataset 用 CLI 能正常挂载（就在上面那个路径）
- 小代码文件（几十KB）可 base64 inline 进 notebook，省得单独建 dataset
- 大文件（如模型 checkpoint）必须走 Kaggle dataset 上传，不能 inline
- 探查/不吃 GPU 的活，用 CPU kernel（enable_gpu: false），别浪费 GPU 配额

### 通用工作流铁律
- 上 Kaggle 或跑任何新东西：先小规模 probe（N=50/200）把整条管线跑通，再全量。
  绝不一上来全量——环境/路径/挂载全是坑，全量跑错白烧时间和配额
- 给执行端（Claudian）的指令要 paste-ready、分步骤、每步停下汇报
- 大文件传输：执行端能直接从 ~/Downloads/ 搬文件（cp），我不用手动拖

### LaTeX / 文档
- 本机装 LaTeX 常因 sudo 密码、缺包失败 → 直接用 Overleaf（零安装，必成）
- Overleaf：图要放进 tex 里引用的那个子目录（如 results/），否则渲染成空白
- NeurIPS 格式：用官方 neurips_20XX.sty，US Letter，单栏，标题区有两条横线

### 项目：ADG（ECE175B 期末，2026春，已交）
- 内容：扩散模型 per-attribute guidance（把 CFG 的一个 w 拆成每属性一个 wₖ）
- conda 环境名：adg
- 模型 checkpoint：用 best_loss.pt（epoch13，真正最优），不是 best.pt
- DDPM 内部属性顺序 [smiling, eyeglasses, male, young]，对应 classifier 索引 31/15/20/39
- DDPM↔classifier 索引映射验证过：DDPM[0]→clf[31], [1]→[15], [2]→[20], [3]→[39]
- 教训：先确认属性映射对，否则整个 interference 矩阵是错的
- 教训：FID 样本太少偏差大（N=200 时 103，N=3000 时 52.68）——FID 要几千张才稳
- 关键文件：vault 的 MyBrain/projects/ece175b-adg/
