# Codex + image2 + presentation 三件套 — AI 做可编辑 PPT 的最强实践

> 视频核心：用 OpenAI Codex 当总导演 + image2 (GPT-Image-2 / DALL-E 升级版) 出视觉素材 + presentation 插件做版式，三件套生成**可编辑** .pptx 文件（不是图片 PPT）。

---

## 1. 发现了什么（一句话）

**2026 年 AI 做 PPT 已经超过"生成图片 PPT" 的层次，能产出 PowerPoint 可打开 + 可拖动每个元素 + 可二次编辑的 .pptx 文件**——这意味着 AI PPT 工作流可以接到企业现有 PowerPoint workflow，不再是"AI 给你看，你重做一遍"。

---

## 2. 三件套的角色分工

### 2.1 Codex 是"总导演"

**职责**：
- 理解用户要做什么样的 PPT
- 拆解任务（大纲 / 内容 / 视觉建议）
- 决定什么时候调用 image2，什么时候调用 presentation 插件
- 文件管理 / 素材管理

**类比**：项目经理——不亲自做事，但 orchestrate 所有专家协同

### 2.2 image2 是"视觉素材生产者"

**职责**：
- 生成 PPT 视觉素材（图片背景 / PNG 元素）
- 闭源最强生图模型，中文支持优秀

**关键 capability**：能在**一张图里展示 8 页 PPT 的浓缩**——让你快速看 3 套风格选 1，省时间

**类比**：美术总监——专业出视觉，但不管 layout

### 2.3 presentation 插件是"排版师"

**职责**：
- 做版式（layout）
- 放置文字 / 图片 / 图表
- 渲染 + 预览 + 检查页面效果
- 最终导出 **可编辑 .pptx**

**关键 differentiator**：导出的不是 PDF / 图片，是真正的 .pptx，每个元素可拖动可编辑

**类比**：排版师——把美术给的素材按规则放进版面

---

## 3. 视频里的实战流程（5 步）

### Step 1: 让 Codex 做大纲

> "请按照这个内容做一个 8 页左右的 PPT，你可以先去生成每一页的大纲和内容，然后给我预览，预览完成之后，等我提示下一步，你再进行下一步的执行。"

**关键设计**：不一步到位，先看大纲 + 等用户 confirm 才下一步

**为什么这么做**：AI 一次 generate 完整 PPT 很容易"方向跑偏"，**中间 checkpoint 让人介入** = 减少返工

### Step 2: 浓缩预览 — 一张图看 8 页

> "imagejar [image2] 模型完全有能力做到一张图里包含这么多的信息量，然后可以一次性让他给我三张，且三张的视觉风格不一样，这样就可以去挑选出一个我认为适合的视觉风格。"

**关键巧思**：让 image2 把 8 页 PPT 浓缩在 1 张图，生成 3 张不同风格

**为什么这么做**：
- 不是 24 张图 (8 页 × 3 风格) 等十几分钟
- 是 3 张图 几十秒，**fast iteration**
- 选定风格再展开成 8 张

### Step 3: 用户挑视觉风格

视频里 3 风格：
1. 常规简约干净
2. 科幻科技风
3. 手写风格

视频选 1 (常规简约) 演示

### Step 4: image2 按选定风格生成每页 PNG 素材

> "请按第一种风格去生成 PPT，需要把里面的每一个视觉元素 / 图片 / 文字都按照 PNG 的格式去生成"

**关键 detail**：每个元素**单独**生成 PNG（不是一张大图），这样 presentation 插件可以**单独操作每个元素**

### Step 5: presentation 插件做最终排版 + 导出 .pptx

> "调用 presentation 插件去制作成一个真正的 PPTX 文档"

跑 10 分钟，输出 8 页可编辑 .pptx

## 4. 为什么这是"当下最强实践"（深度分析）

### 4.1 vs 单独用 image2 直接画图 PPT

**单独用 image2**：8 页全是图片
- ✗ 不能编辑文字
- ✗ 不能调位置
- ✗ 拷贝到正式 PowerPoint 不能改
- ✓ 视觉漂亮

**三件套**：8 页可编辑 .pptx
- ✓ 可编辑文字 / 调位置 / 改图
- ✓ 接现有 PowerPoint workflow
- ✓ 视觉风格统一（image2 出的素材）
- ✗ 多花 10 分钟（值！）

### 4.2 vs Gamma / Tome / Beautiful.ai

| | 视频三件套 | Gamma | Tome | Beautiful.ai |
|---|---|---|---|---|
| 输出格式 | **可编辑 .pptx** | 网页 (导出 .pptx 收费) | 网页 (导出收费) | 自家格式 |
| 视觉质量 | 高（image2）| 中 | 中 | 中-高 |
| 中文 | 优（image2）| 中 | 中 | 弱 |
| 价格 | $20/mo (ChatGPT Plus) | $0-$20/mo | $0-$20/mo | $12-$40/mo |
| 自主度 | 高（Codex orchestrate）| 中 | 中 | 低 |

**核心 differentiator**：**输出真正的 .pptx**——这是任何"AI PPT 网站"都做不到的，因为它们用自家格式锁定用户

### 4.3 vs 自己一步步做

**自己做 8 页 PPT 时间**：3-5 小时（找素材 / 排版 / 改字 / 调色）
**Codex 三件套时间**：1 小时（提示 + 等 + 微调）
**节省**：60-80%

但**质量 trade-off**：
- 高 stake PPT（投资人 deck / 客户 proposal）：你还得人工 polish
- 低 stake PPT（课堂展示 / 内部分享）：Codex 出的够用

## 5. 给 Javen 的实战 actionable

### 5.1 你周二 ECE284 演讲会用得上吗？

⚠️ **现在不要用**——你周二要讲的是 Med-HALT，Yixian 已经做了 Slides 1-8 风格固定。**Codex 三件套生成的不会跟 Yixian 风格 align**，不能直接用。

### 5.2 什么时候用 Codex 三件套有 ROI

**最高 ROI 场景**：
- ECE284 / ECE175B Final Project Presentation —— 7-10 页 PPT，**你自己做** 风格选择 freedom，30 min vs 几小时
- 实习面试时的 personal project demo PPT —— 你 vault 系统介绍 / 个人作品集
- 课程项目 update report 配套 slide deck

**低 ROI 场景**：
- 已有团队 + 风格规范的 PPT (Yixian Med-HALT 这种)
- 需要 detailed 实验图表的（image2 出的图不一定准）
- 高 stake 客户 / 投资人 deck（最后还是要人工 polish）

### 5.3 具体怎么用（在你 vault 流程里）

**Step 1**：在 vault 里写好你 PPT 的内容大纲（markdown）
**Step 2**：把 markdown 发给 Codex CLI 或 ChatGPT（带 Codex），让它分析 + 提议视觉方向
**Step 3**：让它调 image2 + presentation 三件套
**Step 4**：拿到 .pptx 后**最重要的 step**：在 PowerPoint / Keynote 里**人工 polish**——AI 生成的 PPT 80% 好但 20% 总有怪异，你要修

### 5.4 你需要付费吗？

- ChatGPT Plus $20/月已包含 Codex + image generation
- 但 image2 / image generation 在 Plus 有 quota 限制
- 重度用可能要升 ChatGPT Pro $200/月（无限制）

**Javen 推荐**：
- **不升 Pro**——你现在月做 PPT 频率 1-2 次，Plus 够
- 等真的频率上来再考虑

### 5.5 这跟 Claude 体系怎么协作

⚠️ **Claude 目前不能生成 .pptx**——只能写代码 generate .pptx（比如用 python-pptx 库），但需要你自己跑代码

**Hybrid workflow**:
- Claude Code: 内容创作（讲稿、大纲、深度分析）
- Codex 三件套: 视觉 + .pptx 排版

→ 两个工具各自承担擅长的部分

## 6. 注意 limitation

### 6.1 image2 的局限

- **不能生成精确数据图表**——你的 ECE284 实验图、模型 architecture 图、benchmark 表格，image2 还是会画错
- **解法**：用 matplotlib / draw.io / Excalidraw 单独生成数据图，作为 PNG 喂给 presentation 插件
- **Codex 实际上能写 matplotlib 代码生成精确图表**——可以让它先 generate 图表 PNG 再放进 PPT

### 6.2 presentation 插件的局限

- **可能不是 OpenAI 官方插件**——视频没明确说，可能是第三方 (e.g., Magic Slides AI, GAMMA-style plugin)
- **导出的 .pptx 在 PowerPoint 不同版本兼容性可能有问题**——需要测

### 6.3 跟 Codex CLI 的区别

视频用的是 **ChatGPT 里的 Codex**（聊天界面里调用 Codex），不是 **Codex CLI**（终端工具）。两者：
- 网页 Codex：跟 ChatGPT 一样的 chat 体验，可调插件（image generation, presentation）
- Codex CLI：本地终端工具，跟 Claude Code 类似，但模型是 GPT-5

**Javen 实操**：你想试 Codex CLI 而不是网页版的话，安装 Codex CLI 后**没法直接调 presentation 插件**——那是网页生态的特性。
