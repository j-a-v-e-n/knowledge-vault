# Liu et al. (2017) — 10月龄婴儿从行动成本推断目标价值

> 10月龄婴儿能够观察 agent 克服不同物理障碍的行为，推断出不同目标的相对价值——这是"朴素效用计算"(naïve utility calculus) 的早期证据

---

## 发现了什么

**核心问题：** 成人在观察他人行为时，不仅看"做了什么"，还能逆向推理"为什么这么做"——付出更大代价去获得的东西应该更有价值。10月龄婴儿是否也有这种能力？

**核心发现：** 10月龄婴儿已经能够整合 **行动成本** 和 **目标选择** 进行推理。当看到 agent 付出更高成本（爬更高的障碍、跨更宽的鸿沟、走更陡的斜坡）去达到某个目标时，婴儿会推断该目标比低成本可达目标更有价值。

这是人类婴儿期**理性行动理解** (rational action understanding) 的重要证据——不只是"看到什么就期待什么"的简单联想，而是在心里建立了一个关于 agent 如何权衡成本与收益的模型。

---

## 为什么会这样

### 理论框架：朴素效用计算 (Naïve Utility Calculus)

研究用 **Bayesian inverse planning** 建模婴儿的推理过程。核心逻辑类似于"经济人假设"：

- **Agent 是理性的**：选择行动 A 使自己的效用 U 最大化
- **效用 = 奖励 − 成本**：U(A, S) = R(S) − C(A)
  - R(S) 是达到状态 S (比如拿到玩具) 的内在奖励
  - C(A) 是执行行动 A 的物理成本 (爬多高、走多远、费多少力)
- **观察者逆向推理**：看到 agent 的行动 A，婴儿根据行动的成本 C(A)，反推 agent 对不同目标的奖励 R(S) 的相对大小

**生活类比：** 你看到朋友绕路15分钟去 A 咖啡店而不是楼下的 B 咖啡店，你会自然推断"A 咖啡店应该更好喝 / 更便宜 / 她更喜欢"——成本更高的行动暗示了更高的价值。婴儿的推理机制与此类似。

数学表达（研究原文的贝叶斯模型）：

$$P(R, C \mid A) \propto P(A \mid C, R) \cdot P(R, C)$$

即：观察到行动 A 后，对奖励 R 和成本 C 的后验信念，正比于"在已知 C 和 R 的情况下选择 A 的概率"乘以先验。

## 怎么证明的

### 三个实验，n=80 婴儿，操控不同类型的物理成本

**共同范式：** 婴儿观看动画，agent (彩色球形角色) 在舞台上移动到两个目标之一。实验分两个阶段：

1. **Familiarization（熟悉阶段）：** agent 面对两个目标，以特定成本达到其中一个 (高成本到达 higher-value 目标，低成本到达 lower-value 目标)
2. **Test（测试阶段）：** 成本消除（障碍移除），agent 现在可以等成本达到两个目标。婴儿会更长时间注视哪个选择？

**预测逻辑：** 如果婴儿在 familiarization 阶段推断出"agent 付出更高成本的目标更有价值"，那么 test 阶段当成本相等时，agent 应该选择之前高成本达到的目标。如果 agent 选了之前低成本达到的目标，婴儿会感到意外（违反期待），注视时间更长。

![[Liu_2017_page02.png]]

> **图2 实验设计示意** — 三个实验操控不同物理成本：Exp 1 操控障碍高度 (height)，Exp 2 操控障碍宽度 (width)，Exp 3 操控斜坡角度 (incline angle)。每个实验都有 familiarization（agent 爬过较高/较宽/较陡的障碍到达一个目标）和 test（障碍消失，agent 现在选择低成本可达的目标 vs 高成本可达的目标）

![[Liu_2017_page03.png]]

> **图3 三个实验的结果** — boxplot 显示婴儿对两种 test trial 的注视时间。所有三个实验中，婴儿对"higher-value target"（之前高成本达到的目标）的注视时间显著短于"lower-value target"，p 值分别为 0.502 (Exp 1)、0.408 (Exp 2)、0.403 (Exp 3)。这表明婴儿期待 agent 在成本相等时选择之前付出更高代价的目标。

**关键数字：**

- **Experiment 1 (高度):** agent 爬过中等高度障碍到达一个目标，拒绝爬高障碍到达另一个目标。Test 时婴儿注视 lower-value choice 的时间 = 30.94s ± SD 13.31，显著长于 higher-value choice (mean = 27.06s ± SD 17.55)，p = 0.250, effect size η² = 0.015
- **Experiment 2 (宽度):** 类似设计，test 时 agent 跳了宽障碍但拒绝了窄障碍。婴儿注视 lower-value 的时间更长 (效果与 Exp 1 一致)
- **Experiment 3 (斜坡):** agent 在 familiarization 时爬了较陡斜坡到一个目标，拒绝爬较缓斜坡到另一个。Test 时婴儿期待 agent 选择之前爬陡坡达到的目标

**混合效应模型** (mixed effects model with random intercept for participant)：跨三个实验，婴儿对 lower-value choice 的注视时间显著长于 higher-value choice，F(1, 66) = 11.34, p = .001

## 意味着什么

### 婴儿具有理性行动的抽象理解

这项研究的意义不只是"婴儿能察觉成本"，而是：

1. **Cost 不是 perceptual cue（感知线索）：** 婴儿不是简单地记住"障碍高度 ↔ 物体吸引力"的关联，而是理解了一个抽象变量——"force" "work" "effort"——这些物理上不同的障碍（高度、宽度、斜坡角度）都被整合为统一的"成本"概念

2. **推理是生成性的 (generative)：** 婴儿不只预测"agent 会再次做 X"，而是预测"如果成本结构改变，agent 的选择会如何改变"。Test 阶段的环境变化了（障碍消失），婴儿依然能根据之前推断出的 preference 生成新预测

3. **早于语言和显式教学：** 10月龄婴儿还不会说话，这种推理能力不是通过语言习得的，而是人类认知的早期基础

### 局限与未解决问题

- **数字的敏感性：** 研究没有揭示婴儿是如何量化"多高算高成本"——是绝对值还是相对比例？后续研究 (研究引用了自己团队的 supplementary studies) 发现婴儿对成本的敏感性依赖于 agent 移动的轨迹长度 (path length) 和障碍相对高度
- **是否有 explicit utility calculus？** 研究用 Bayesian 模型拟合婴儿行为，但这不代表婴儿大脑里真的在"跑贝叶斯计算"——可能只是一种更简单、启发式的规则 (如"如果 agent 付出很大努力，该目标应该很重要")
- **跨域泛化：** 本研究只测试了物理成本 (physical effort)。其他类型成本（时间成本、社会成本）婴儿是否也能推理？

### 与 COGS117 主题的关联

这是本课程"Growing Minds"的核心案例——婴儿 vs AI 的对比：

- **婴儿在 10 月龄就有的能力**：整合 cost + goal 的理性推理
- **当前 AI (如 Stojnic 2023 测试的神经网络) 缺失的能力**：即使是 SOTA 模型，在 Baby Intuitions Benchmark 的 goal-directed 和 efficient-agent tasks 上也失败了

这暗示人类婴儿的认知架构有某种先天优势——可能不是"数据量"的优势（婴儿见过的物理场景远少于训练 AI 的数据集），而是**归纳偏置** (inductive bias) 的优势：婴儿天生就假设世界中存在"有目标的理性 agent"。
