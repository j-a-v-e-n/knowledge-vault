# Herrmann, Call, Hernández-Lloreda, Hare & Tomasello (2007) — 文化智力假说

> 2.5 岁人类儿童 vs 黑猩猩 vs 红毛猩猩在 16 项认知 task 上的全面对比：在**物理认知** domain 人 ≈ 黑猩猩，但在**社会认知** domain 人 ≈ 2 倍其他猿——支持"人类大脑大不是 general intelligence，而是 specialized social cognition for cultural participation"。

---

## 这项研究在解决什么问题？

**为什么人脑比猿脑大 3 倍？**

两个对立 hypothesis 长期没有 direct test：

| Hypothesis | Prediction |
|---|---|
| **General Intelligence** | 人在 **所有** cognitive domain（memory / 学习 / 推理 / planning）都比猿强 |
| **Cultural Intelligence**（Tomasello 团队提出） | 人只在 **social-cognitive** skills 上 specialized 强（communicate / learn from others / theory of mind），物理 cognition 跟近亲 ape 应类似 |

**关键 gap**：以前从来没有人用 **same individuals + same battery + before-schooling age** 同时测多个 primate species。已有数据全是不同实验、不同年龄段、不同任务——meta-analysis (Deaner et al. 2006) 也没含 humans。

→ 本研究是 **首次 systematic comparison**。

## 核心论点（一句话）

**Pre-literacy 2.5 岁儿童 在物理认知上跟黑猩猩 statistically 相等 (0.68 vs 0.68)，但在社会认知上 2 倍 于黑猩猩 (0.74 vs 0.36)——支持 Cultural Intelligence Hypothesis，反驳 General Intelligence Hypothesis**。

---

## 方法：Primate Cognition Test Battery (PCTB)

### 16 项 task，跨 2 个 domain × 3 个 scale

| Domain | Scale | Task（item × trial） | 描述 |
|---|---|---|---|
| Physical | Space | Spatial memory (1×3) | 找 hidden reward |
| | | Object permanence (3×9) | invisible displacement 后追踪 reward |
| | | Rotation (3×9) | rotation 后追踪 reward |
| | | Transposition (3×9) | location change 后追踪 reward |
| | Quantities | Relative numbers (1×13) | 区分量的多少 |
| | | Addition numbers (1×7) | 加法后量判断 |
| | Causality | Noise (2×6) | hidden reward 发出 noise 的 causal 理解 |
| | | Shape (2×6) | hidden reward 改变 shape 的 causal 理解 |
| | | Tool use (1×1) | 用 stick 取够不着的 reward |
| | | Tool properties (5×15) | 功能 vs 非功能 tool property 理解 |
| Social | Social learning | Social learning (3×3) | 观察 demonstration 解 non-obvious problem |
| | Communication | Comprehension (3×9) | 理解 communicative cue 指 reward 位置 |
| | | Pointing cups (1×4) | **产生** communicative gesture 取 reward |
| | | Attentional state (4×4) | 根据 recipient 的 attention 调整 gesture |
| | Theory of mind | Gaze following (3×9) | 跟随 actor's gaze 到 target |
| | | Intentions (2×6) | 理解 actor 想做但失败的事 |

### Subjects（verbatim）

- **106 chimpanzees** (53♂/53♀，3–21 岁，平均 10 岁) — Ngamba Island Uganda + Tchimpounga Congo sanctuaries
- **32 orangutans** (17♂/15♀，3–10 岁，平均 6 岁) — Orangutan Care Center Indonesia
- **105 human children** (52♂/53♀，2.5 岁 ± 2 个月) — 德国中型城市；已用语言 ~1 年

三组都 **naïve to tests**；apes 都住在 captivity 中"最丰富 social + physical environment"。

### Administration

- 一位 human experimenter (E1) 全程一致
- 通过 Plexiglas window（儿童 + 部分 ape）或 mesh panel（ape only）测
- 3 hole window 让 subject 用手指选择
- Reward 位置 counterbalanced
- 全程 video record
- 儿童：5 天内完成（2 周窗口）；ape：连续 8 天平均
- **Inter-observer agreement**: orangutan 98%, chimp 99%, human 99%

## 关键数据（Table 2，全 verbatim from paper）

**Upper-level summary（按 domain）**：

| | Human | Chimp | Orang |
|---|---|---|---|
| **Physical (overall)** | 0.68ᴼ | 0.68ᴼ | 0.59 |
| **Social (overall)** | **0.74ᶜ·ᴼ** | **0.36** | **0.33** |

> 上标 H/C/O 表示该值显著高于 human/chimp/orang 对应值（P < 0.001 全部）。

**Physical scales（人 ≈ 黑猩猩，红猩猩较弱）**：

| | Human | Chimp | Orang |
|---|---|---|---|
| Space | 0.71ᴼ | 0.71ᴼ | 0.60 |
| Quantities | 0.67 | 0.68 | 0.63 |
| Causality | 0.65ᴼ | 0.66ᴼ | 0.55 |

**Social scales（人 ≫ 黑猩猩 ≈ 红猩猩，**所有 P < 0.001**）**：

| | Human | Chimp | Orang |
|---|---|---|---|
| Social learning | **0.86ᶜ·ᴼ** | **0.10** | **0.07** |
| Communication | 0.72ᶜ·ᴼ | 0.57 | 0.55 |
| Theory of mind | 0.65ᶜ·ᴼ | 0.40 | 0.36 |

> **Social Learning 是全 battery 最 stark 的差**：人 0.86 vs 猿 0.07–0.10。

**Task-level 关键 surprise（chimp 比 human 强的 task）**：

| Task | Human | Chimp | Orang |
|---|---|---|---|
| **Transposition** | 0.57 | **0.70ᴴ·ᴼ** | 0.47 |
| Addition numbers | 0.64 | **0.69ᴴ·ᴼ** | 0.61 |
| **Tool use** | 0.23 | **0.74ᴴ·ᴼ** | 0.38 |

> Chimp 在 active tool use 上几乎是 2.5 岁人类的 3 倍。这是 paper 自己强调的 limit：human 在 causality 上的优势主要是 **passive judgment**（理解 hidden cause），不是 active manipulation。

**Comprehension 任务里"pointing cups"很特殊**：

| Pointing cups | Human 0.72 | Chimp 0.74 | Orang 0.73 |

> **三个物种基本相等**——产生 communicative gesture（点指）对 ape 跟人一样容易。差距集中在 **理解 + 用 attention state 调整 gesture**（comprehension + attentional state）。

## 统计强度（paper Fig 1 & 2 caption verbatim）

**MANOVA across 全 battery**：
- Wilk's Lambda: F₄,₄₇₂ = 123.965, **P < 0.001**, η² = 0.51

**Domain 级 ANOVA**：
- Physical: F₂,₂₃₇ = 19.921, P < 0.001, **η² = 0.14**
- **Social: F₂,₂₃₇ = 311.224, P < 0.001, η² = 0.72** ← effect size 巨大

**Social scales 内（全 P < 0.001）**：
- Social learning: F₂,₂₃₇ = 382.145, η² = 0.76
- Communication: F₂,₂₃₇ = 24.717, η² = 0.17
- Theory of mind: F₂,₂₃₇ = 70.646, η² = 0.37

**Effect size 对比**：social domain η² = 0.72 是 physical domain η² = 0.14 的 **5 倍** → 人的 cognitive advantage 不是 uniform，是 **strongly localized 在 social cognition**。

## 辅助变量（控制 confound）

### Gender effect
- Human ♀ > ♂ in Quantities (P = 0.004) + physical domain overall
- Chimpanzee ♂ > ♀ in Space (P = 0.047) — 跟前人研究 fit
- **没 gender × species interaction in social domain** — 排除 gender 解释

### Temperament（关键 control）
- 儿童 in test situation 比 ape **更 shy / less interested** (P < 0.001)
- 但 **儿童 temperament 跟所有 cognitive score 不相关**
- → 排除 alternative explanation "apes 没把 test 当回事所以分低"

### Inhibitory control
- 儿童 > chimp > orang
- 但 inhibitory control 只跟 **physical domain** performance 相关，**跟 social domain 不相关**
- → social 优势不是 just better inhibition

### Variability
- 95% CI 两侧：三物种间个体 variability **没显著差**
- ape 比 human genome-wise 更 variable（Fischer et al. 2006）, 但 cognitively variability 类似

## paper 自己承认的 caveats

1. **Alternative interpretation**：children 也在 non-tool causality task 上 better。**可能** distinctively human 不是 social cognition per se，而是 **"understanding unobserved causal forces in general"**——mental state 作为 special case 的 hidden cause。 paper §"Discussion" verbatim:
   > "what may be distinctive is the ability to understand unobserved causal forces in general, including (as a special case) the mental states of others as causes of behavior"

2. **Test administered by humans** — 可能 bias，但 paper note：
   - Previous studies with same tasks 用 conspecific 测试者 results 类似 (table S2)
   - Temperament 不相关 social performance — 排除 "apes 不懂 humans 所以分低"

3. **H. erectus 时期社会认知** ：paper §"Discussion" 提：1–2 mya 的 H. erectus brain growth pattern 更接近 chimp 而非 modern human (Coqueugniot et al. 2004), 且当时 cultural differences between groups 证据很少 (Klein 1999) → social-cultural cognition skills 可能那时还**没**演化出来

4. **Sample restriction**：apes 都是 **sanctuary-raised + close contact with humans**——不是 wild。可能 inflated 它们的 social cognition 分（vs wild ape 应更低）

5. **Test battery construction** — "we of course could have obtained different results with a different test battery"。 paper 强调 PCTB 来自 Tomasello & Call (1997) 的 comprehensive theory，但 admit：
   > "there would be more consensus among experts about the appropriateness of our tasks of physical cognition, whereas there might be more controversy about the social tasks"

---

## ⚠️ 矛盾与未解决问题

- **跟 General Intelligence Hypothesis (Jerison 1973) 直接对立**：paper 数据强 disconfirm。但 GIH 支持者可重 frame："human 的 social cognition 是 general intelligence 的 application 到 social domain"——paper 自己 alt interpretation 也承认这种可能

- **Dog 对比 (Hare et al. 2002; Bräuer et al. 2006)** — 跟核心 thesis 互补：
  > "domestic dogs (Canis familiaris) (which, in some sense, have been selected to live in human cultures) do not perform as well as chimpanzees on tasks of physical cognition but outperform them on tasks of social cognition"

  → **跨人类环境的选择压力**也能 produce social-cognitive advantage——支持 Cultural Intelligence Hypothesis 的"环境 + selection 共同作用"机制

- **Tool use 黑猩猩 0.74 vs 人 0.23 矛盾**：黑猩猩 active tool use 远超 2.5 岁儿童——人类 active causal manipulation 似乎不是早发优势。 paper 没深入这条 contradicts uniform "humans better at causality" 的简化解读
