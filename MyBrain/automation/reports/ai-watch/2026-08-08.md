## 70% — Broad Horizon

### ⚡ Simon Willison 的 `llm` CLI 出 0.32 —— server-side tools 成一等公民
- **What**: 8/4 发布，作者自称"自初版以来最重大的一次更新"。三件事：(1) **reasoning traces** 打到 stderr，能单独看模型"思考"过程（`-R` 可关）；(2) 接 **OpenAI Responses API**，直接调 CodeInterpreter / WebSearch 这类 server-side 工具；(3) OpenAI 和 Anthropic 两边都开放 server-side tools。配套 **llm-anthropic 0.26** 加了 Claude 5 家族支持 + WebSearch / WebFetch / CodeExecution / **AnthropicMCP** 连接器。
- **Why interesting**: 过去"agent 工具"要自己在代码里拼 tool loop，现在一行 CLI 就能调云端 web search / code exec —— 本地脚本和云端 agent 能力的边界在消融。这是 coding-agent 生态"工具标准化"的一个清晰信号。
- **Source**: https://simonwillison.net/2026/Aug/4/new-release-of-llm/ (fetched 2026-08-08)

### 🔍 NVIDIA 开源 NOOA agent 框架
- **What**: NVIDIA Labs 开源 **NOOA (NVIDIA Object-Oriented Agents)**，一个 model-agnostic 的 Python agent 框架（不锁定某个模型）。
- **Why interesting**: 又一个大厂下场做 agent 编排框架；"model-agnostic"是当下的主流姿态（跟你 task-019 subagent 团队 + task-013 router 想接 DeepSeek 是同一个哲学：把模型当可替换后端）。
- **Source**: WebSearch (llm-stats / modal 2026-08 汇总)

### 🔍 Kimi K3 —— 迄今最大开源权重模型
- **What**: Moonshot AI 7/16 在上海 WAIC 发的 **Kimi K3**，2.8 万亿参数 MoE，每 token 激活 ~50B（896 选 16 experts），1M context，原生多模态。
- **Why interesting**: 开源阵营的"前沿追赶"—— 开源 VLA 今年预计能到闭源 80% 水平（同 Llama vs GPT 的轨迹），大 LLM 这边 Kimi K3 是同一趋势的顶点。开源模型正在从"够用"往"接近前沿"移。
- **Source**: WebSearch (llm-stats 2026-08 / fireworks.ai)
