## 70% — Broad Horizon

### ⚡ Anthropic "Code with Claude 2026"：没有新模型，但推出了 Managed Agents 基础设施
- **What**: Anthropic 在 Code with Claude 2026 开发者大会上没发布新旗舰模型，而是聚焦在 agent 基础设施上。核心新功能：**Dreaming**（定期审查 agent session + memory store 的后台进程）、**Multi-agent Orchestration**（lead agent 分解任务 → 派给并行运行的 specialist sub-agent，共享文件系统）、**Outcomes**（定义"好输出"的 rubric，用独立 grader 反复打分直到达标）。同步提高了 Claude Code 和 Opus API 的 rate limit。
- **Why interesting**: 这次发布信号非常清楚：Anthropic 认为 agent infra 比堆新模型更重要。Dreaming（自我内省 + 记忆维护）和 Outcomes（自我评估 loop）是 autonomous agent 走向生产的两个关键缺口，现在有了官方解决方案。这比新参数多 10% 的模型发布影响深远得多。
- **Source**: [Code with Claude 2026: 5 New Agent Features — MindStudio](https://www.mindstudio.ai/blog/code-with-claude-2026-new-agent-features) / [Anthropic news](https://www.anthropic.com/news)

### ⚡ Anthropic Mythos 震动白宫：AI 安全模型逼出政策转向
- **What**: Anthropic 的 Mythos 模型（尚未公开发布）被描述为"能发现数十年前埋下的安全漏洞"，其能力强到让 Trump 政府重新考虑之前一贯的"放任"AI 监管立场，开始讨论新模型发布前的政府介入评审机制。同时 Anthropic 年化营收突破 $300 亿，1000+ 家企业每年花超 $100 万用 Claude，2 个月内翻倍。
- **Why interesting**: Mythos 是目前已知最接近"真正危险能力"门槛的模型，连政策制定者都感到震惊到需要改变态度。这条线（frontier model capability → regulatory response）是 2026 年 AI 最重要的叙事之一。Anthropic 拿 $300 亿营收说明 Claude 在企业端已经是 production-grade 基础设施。
- **Source**: [OpenAI EU cyber model, Anthropic Mythos — CNBC](https://www.cnbc.com/2026/05/11/openai-eu-cyber-model-anthropic-mythos-gpt.html) / [White House AI policy shift — The Hill](https://thehill.com/policy/technology/5870495-white-house-ai-policy-shift/)

### 🔍 OpenAI + Amazon Bedrock：stateful agent 执行环境正式合作
- **What**: OpenAI 和 Amazon 宣布合作，在 Amazon Bedrock 上构建有状态（stateful）的 agent 执行环境，统一管理 agent memory、tool connections 和 user permissions。同时 Nvidia 发布 Nemotron 3 Super 120B，专为 agentic workflow 优化，支持 1M token context，开权重。
- **Why interesting**: "无状态 agent 沙箱"是目前企业部署 agent 的最大痛点之一——每次调用都要重建 context 太贵。OpenAI + Bedrock 的 stateful 环境直接解决这个问题，且绑定了 AWS 的企业客户生态。Nvidia 的 Nemotron 3 Super 提供了一个 120B 级别的开源 agentic backbone。
- **Source**: [AI agent adoption 2026 — Joget](https://joget.com/ai-agent-adoption-in-2026-what-the-analysts-data-shows/) / [Cloudflare LLM infrastructure — InfoQ](https://www.infoq.com/news/2026/05/cloudflare-llm-infrastructure/)

### 🔍 Colorado AI Act 6 月 30 日生效：首个要求"影响评估"的美国州法
- **What**: Colorado AI Act 将于 2026 年 6 月 30 日正式生效，要求企业对 high-risk AI 应用做安全风险管理、影响评估（algorithmic impact assessment），以及防止歧视的措施。加州 S.B. 53 已在今年年初生效（强制 frontier AI 开发者发布安全框架）。EU AI Act 的高风险合规截止日期则推迟到 2027-2028 年。
- **Why interesting**: 美国从"联邦层面放任 + 州层面各自立法"的格局正在形成实际约束。6 月 30 日是一个硬截止日期，任何在科罗拉多州有业务的 AI 公司都必须合规。对于未来做 AI 产品的人：impact assessment 是即将成为标准实践的流程，早学早受益。
- **Source**: [2026 AI Laws Update — Gunderson Dettmer](https://www.gunder.com/en/news-insights/insights/2026-ai-laws-update-key-regulations-and-practical-guidance) / [AI regulation 2026 — Kiteworks](https://www.kiteworks.com/cybersecurity-risk-management/ai-regulation-2026-business-compliance-guide/)

### 💡 给 Javen 的落地切入点

**1. Claudian daemon 直接受益于 Managed Agents**：Anthropic 新发布的 Outcomes（grader loop）和 Dreaming（自我内省 + memory review）正好是这个 dawn-shift daemon 缺少的能力。如果之后想升级 daemon 架构，这两个功能的 API 值得优先研究。Dreaming 可以做"昨晚失败的任务分析"，Outcomes 可以自动评估每晚 daemon 报告质量。

**2. Qwen3 Coder Next 值得 benchmark 一次**：如果有 ECE 课程作业或个人项目需要代码辅助，Qwen3 Coder Next 作为开源代码模型可以在本地跑或用 API，成本远低于 GPT-4o / Claude Opus。5 月下旬刚发布，文档新鲜，现在试是最好时机。

**3. Mythos 和安全漏洞检测**：如果 ECE 课程或研究涉及 security（ECE 184? 信息安全相关），Anthropic Mythos 的"自动发现数十年前代码漏洞"能力是值得关注的研究方向。这会在 software security 领域引发很多新的研究问题。

**4. Colorado AI Act 影响评估模板**：6 月 30 日截止，网上现在开始有公开的 impact assessment template 出现。如果将来要做 AI 产品，提前看一份 template 让你对"负责任 AI"的行业实践有具体概念，比只读理论有用得多。
