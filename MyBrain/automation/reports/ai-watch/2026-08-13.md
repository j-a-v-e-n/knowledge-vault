### 🔍 微软 BUILD 2026 推 Agent Framework 三件套
- **CodeAct**: 让模型**写 Python 程序调工具**（`call_tool()`）而不是一步步顺序调工具——representative benchmark 上 **时间 -52.4% / token -63.9%**。跑在轻量 Hyperlight micro-VM 里。
- **Agent Harness**: 给 agent 加"生产执行层"——shell/文件系统访问 + human-in-the-loop 审批 + 自动 context compaction 防 token 溢出 + 文件记忆持久化。（听着眼熟？就是你 daemon 手搓的那套。）
- **Hosted Agents (Foundry)**: scale-to-zero，idle 不花钱，VM 隔离沙箱 + OpenTelemetry 可观测。
- **Source**: https://devblogs.microsoft.com/agent-framework/microsoft-agent-framework-at-build-2026-announce/
