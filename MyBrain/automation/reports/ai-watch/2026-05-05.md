## 70% — Broad Horizon

### ⚡ NVIDIA Isaac GR00T 新开源模型 — 机器人能听懂自然语言了
- **What**: NVIDIA 发布新一代 Isaac GR00T 开源模型，机器人可理解自然语言指令并执行复杂多步任务，使用 VLA（视觉-语言-动作）推理框架，且完全开源可本地跑。
- **Why interesting**: 上一批 VLA foundation model（RT-2、ABot-M0）大多闭源或数据集私有；GR00T 开源意味着可以直接 fine-tune 到具体任务，开发者门槛大幅降低。Robotics 领域这相当于 GPT-2 开源时的时刻。
- **Source**: [NVIDIA Blog — National Robotics Week](https://blogs.nvidia.com/blog/national-robotics-week-2026/) (fetched via search 2026-05-05)

### 🔍 AGIBOT GO-2：从"黑盒探索"到"推理-执行统一"
- **What**: AGIBOT 发布 GO-2 基础模型，把逻辑推理和动作执行统一进单一架构；训练数据包含数万小时交互数据，核心突破是真正做到"想清楚了才执行"而不是黑盒端到端。
- **Why interesting**: 之前 VLA 模型最大的槽点是动作不可解释。GO-2 的 reasoning-before-action 思路跟 LLM chain-of-thought 对齐，是工程上更可维护的方向。
- **Source**: [The Robot Report — AGIBOT GO-2](https://www.therobotreport.com/agibot-releases-go-2-foundation-model-embodied-ai/) (fetched via search 2026-05-05)

### 🔍 Google Cloud A2A 协议正式 production-grade
- **What**: Google Cloud Next 宣布 Agent2Agent（A2A）协议进入生产级，允许跨平台 AI agent 互相通信；同时发布托管 MCP 服务器、200+ 模型的开发者市场（含 Anthropic Claude）、Workspace Studio no-code agent builder。
- **Why interesting**: A2A 是第一个严肃的 cross-vendor agent 通信标准。Claude Code 已经基于 tool-use/MCP 做了类似的事——A2A 如果普及，agent 系统会从"单厂商孤岛"变成可组合的乐高。
- **Source**: [The Next Web — Google Cloud Next 2026](https://thenextweb.com/news/google-cloud-next-ai-agents-agentic-era) (fetched via search 2026-05-05)

### 🔍 五角大楼 AI 协议：8 家大厂进，Anthropic 因安全条款出局
- **What**: 五角大楼与 SpaceX、OpenAI、Google、Microsoft、NVIDIA、AWS、Oracle、Reflection 签署协议，允许其 AI 接入机密网络。Anthropic 未入选——原因是 Anthropic 坚持要求 Pentagon 在军事 AI 使用中保留安全护栏，Trump 政府拒绝这一条件。
