## 70% — Broad Horizon

### ⚡ 一篇 position paper 在给机器人学界泼冷水："光靠 VLA + world model 撑不起来"
- **What**: arXiv [Robots Need More Than VLAs & World Models](https://arxiv.org/html/2606.06556v1) 主张——机器人学习的真正瓶颈**不是**把 VLA 模型堆更大、demo 喂更多，而是缺"把海量非结构化行为数据（人类动作、网络视频、仿真回放、机器人失败记录）转成可用监督信号"的机制。它提出四个缺失件：物理数据引擎（自动标注异构经验）、任务保持的 retargeting（人体动作跨机器人本体迁移）、physics-grounded world model（预测**可执行后果**而非只是好看的画面）、自改进部署闭环（把真实失败转成学习信号）。
- **Why interesting**: 一个月内各家还在刷 VLA/embodied 模型（昨天的 ACE-Brain-0.5 就是），这篇反过来说"范式重心该从 scaling policy 转向 grounding 数据"。这种"泼冷水"的 position paper 往往预示下一波研究方向。

### 🔍 反直觉发现：VLM 在标准 benchmark 上的分数，跟它当 VLA backbone 的下游表现**不相关**
- **What**: VLM4VLA 系统对比了不同 VLM 作 VLA 骨干，结论是——VLM 在常规视觉语言 benchmark 上更强，**并不**代表拿去做机器人 VLA 就更强，两者无相关性。
- **Why interesting**: 直接质疑"选最高分 VLM 当机器人大脑"的默认做法；提醒 embodied 任务需要自己的评测轴，不能借用聊天/看图榜单。

### 🔍 HuMI：用"无机器人"的便携人体示范采数据，绕开 teleoperation 瓶颈
- **What**: HuMI 用可携带、不需要真机器人的人体演示来学全身人形操作技能，数据采集效率比传统遥操作（teleoperation）显著更高。
- **Why interesting**: 数据采集是机器人学习最贵的一环，"人直接示范→迁移到机器人"这条路线如果 work，能把采数据成本砍一大截。呼应上面那篇 position paper 的 retargeting 论点。

### 🔍 xAI 把 Grok Build 的 agent loop + TUI 开源了（7/15）
- **What**: xAI 开源了 Grok Build coding agent 的核心——context assembly、tool dispatch、终端 UI、扩展系统，支持 local-first（指向本地推理跑）。加上 Aider / Cline / Kilo Code，开源 coding agent 生态这个月很热。
- **Why interesting**: 以前 coding agent 的"编排循环"都藏在闭源产品里，现在核心骨架能直接读源码——对想理解 agent 到底怎么运作的人是一手材料。
