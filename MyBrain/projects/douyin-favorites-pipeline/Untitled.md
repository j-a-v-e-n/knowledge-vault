Anthropic 团队的 Dickson Tsai 在 Code with Claude 大会上介绍了 Claude Code 的多项新功能，推动其从终端工具向 Agent 平台转变。

远程控制功能：用户可在电脑开启 Claude Code 会话，通过手机网页或 APP 接入同一会话，同步使用同一开发环境，支持外出时继续处理长任务。
无闪烁渲染：Claude Code 终端新增全屏模式，将滚动回滚虚拟化，实现零闪烁渲染，同时支持点击终端元素，长时间会话内存占用保持平稳。
GUI 优化升级：Claude Code 桌面版和网页版 GUI 新增分屏视图、评论添加、章节固定跳转等功能，可按项目分组管理会话，提升多会话处理效率。
自动权限模式：Claude 会通过分类器判断工具调用是否具有破坏性或提示注入风险，安全操作自动运行，避免用户因权限提示中断长任务。
工作树功能：用户可通过命令或指令让 Claude 创建独立工作树，支持多会话并行处理不同功能，工作树间可共享指定文件，完成后可自动清理。
自动记忆功能：Claude 会在会话中积累项目知识，管理记忆目录文件，自动记录关键构建命令、调试见解等信息，也适用于子代理。
多代理代码审查：支持多阶段多代理代码审查，可通过 GitHub 应用或手动触发，能捕捉易遗漏的代码问题，节省用户审查时间。
自动化例程功能：用户可配置提示、仓库和触发器（定时、GitHub 事件或 API 端点），让 Claude 自动运行任务，还可通过 /loop 指令设置会话内自动化。

用户可通过公共变更日志、X 平台 Claude Devs 账号、每周文档摘要或开发者时事通讯了解 Claude Code 的后续更新。
