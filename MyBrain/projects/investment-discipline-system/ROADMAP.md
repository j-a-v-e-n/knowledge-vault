# 路线图｜投研纪律系统

路线图描述方向和依赖关系，不是对未来功能的无条件承诺。

## 当前阶段：建立可靠的工作基础

- 把 AI 协作从临场对话整理成有状态、可验证的工作流。
- 建立项目空间，让目标、状态、任务、决定和证据能在长周期协作中持续可见。
- 调研已有工具和真实使用经验，遵守“先复用，再构建”的入口规则。

## 后续阶段：投研系统设计与第一个纵切片

- 固化研究输入、事实与推断、建议、决策、风险检查和记录之间的流程。
- 先实现能完整走通的最小闭环，再扩展数据源和分析能力。
- 在纸面环境中积累足够的可核对样本，并与基准并列复盘。
- 只有在预先定义的证据和风险门槛满足后，才讨论真实资金。

## 再后续阶段：验证与迭代

- 对策略想法执行严格历史检验和留出检验。
- 监控数据质量、规则漂移、模型表现、交易成本和实际执行偏差。
- 把失败、拒绝交易、越界拦截和不确定性作为一等记录。

## 未来扩展方向

- 把本项目采用的项目工作系统抽象为可接入任意项目的通用产品或附属能力。
- 支持多个项目共享同一套状态、任务、决定、证据和协作协议。
- 若未来服务其他人，再增加身份、权限、隐私、数据隔离、审计、部署、支持和适用的合规要求。
- 评估与 GitHub 等版本和备份工具的连接。

未来方向只有在当前阶段的边界、证据和维护成本被重新评估后才进入实施。
