# 路线图｜投研纪律系统

更新时间：`2026-07-25`

路线图描述依赖关系，不把未来愿望伪装成当前承诺。

## 当前：方法挑战与设计冻结

- 完成 AI 长周期做项目的失效地图、传统工程映射和普通用户经验检索。
- 让只读挑战者攻击遗漏、假独立、可投机控制和“全绿但用户目标失败”路径。
- 冻结用户意图、要求、失效、保障主张和机器可读验收合同。
- 将旧原型审计反例升级为新内核的前置失败测试。

## 下一阶段：可信内核

- 建立 SQLite 单一事实源、不可变 run manifest 和事务内事件链。
- 实现完整订单意图哈希、权威风险状态、不可变政策版本和延迟修订。
- 实现可重启、可重放、幂等、可对账的本地 PaperAccount。
- 实现外部尾锚、备份、恢复和 schema migration。

## 下一阶段：诚实投研闭环

- 实现时间可知性快照、来源/修订谱系、raw + actions 本地调整。
- 实现假设预注册、试验谱系、留出消费记录、成本和基准。
- 实现结构化 AI 建议、人工决定、premortem、情绪和 no-trade。
- 实现 AI 建议、人工决定和基准三轨复盘。

## 下一阶段：本地工作台与适配器

- 从同一事实源生成 Today、Research、Decision、Discipline、Evaluation 和 System 视图。
- 设计 calm UI，不使用 top movers、排行榜、彩带或闪烁 P&L。
- 完成 Tiingo 只读适配器的离线契约和故障注入。
- 无个人凭据时只运行公开 demo 结构探针；不把它扩大为生产质量通过。

## 发布候选：独立验收与恢复

- 在干净目录运行机器检查、黑盒旅程、故障注入和浏览器 QA。
- 从明确 GitHub commit 恢复代码，从私人备份恢复运行状态。
- 由未参与构造的审查者生成额外反例并审查需求覆盖。
- 用户立场检察官逐条重放原始目标；open critical/major 阻止完成。
- 发布包同时列出已证明、未证明、已拒绝和已知缺口。

## 发布后：纸面前瞻样本

- 使用固定小宇宙和周/月节奏积累真实未来样本。
- 监控建议校准、纪律偏离、成本、数据修订和基准差。
- 任何真实资金讨论必须另建目标、授权、风险和验收合同。

## 未来扩展

- 把本项目验证过的项目工作内核抽象为通用项目系统。
- 需要历史动态选股时评估 Sharadar 或 Norgate Security Master。
- 需要观察外部 Paper 协议时再评估 Alpaca Paper；它不取代本地权威账。
- 多用户、商业化、部署、身份、权限、隐私隔离、支持和合规。

未来项只有在当前证据、维护成本和风险重新评估后才进入实现。
