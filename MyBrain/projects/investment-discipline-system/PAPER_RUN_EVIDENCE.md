# 纸面运行证据｜原型阶段

## 运行对象

这是使用本地保存的 FRED 日收盘 CSV 进行的真实来源管线案例。研究对象和基准都是价格指数，因此该案例只验证流程、数据边界、纸面闸门、账本和复盘，不代表可直接交易的资产，也不证明策略有效。

## 可复核入口

- 原型入口：prototype/run_real_data_case.py
- 来源说明：DATA_SOURCE_POLICY.md
- 运行报告：本地 prototype/data/runs/real_data_case_v2/case_report.md
- 结构化结果：本地 prototype/data/runs/real_data_case_v2/case_result.json
- 事件账本：本地 prototype/data/runs/real_data_case_v2/ledger.jsonl
- 运行命令：python3 -m prototype.run_real_data_case

## 已验证行为

- 决策只使用决策时点之前的来源观察。
- 纸面操作经过确定性风险闸门。
- 人工决策、建议偏离状态、情绪说明和规则版本进入事件记录。
- 纸面操作、拒绝原因、基准复盘和来源哈希进入追加式账本。
- 账本可以在重新加载后验证。
- 缺失观察会使案例失败，不会静默跳过。
- 来源快照或计算版本变化时，不会覆盖旧运行结果。

## 证据边界

- 原始来源文件和运行产物被 Git 忽略，只保存在本地。
- 派生收益字段是程序计算结果，不是来源事实。
- 成本参数仍是未校准的演示假设。
- 当前案例不包含新闻、基本面、公司行动、总回报基准、真实券商或真实资金。
- 进入正式系统前必须重新决定市场、可交易资产、数据许可、复权方式、基准和风险参数。
