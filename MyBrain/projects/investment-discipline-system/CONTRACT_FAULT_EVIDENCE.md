# 数据与执行契约故障注入证据

## 目的

在没有接入任何外部供应商前，先验证核心对异常状态的处理方式，避免把供应商 API 的成功响应路径误认为完整系统。

## 已覆盖

- 决策后才可见的数据进入拒绝路径。
- 没有成交记录的部分成交状态被视为无效。
- 没有原因的未知执行状态被拒绝；有原因的未知状态进入待对账语义。
- 相同订单号重复提交不会重复改变本地纸面账户。

## 可复核入口

    python3 -m prototype.run_contract_faults

运行产物位于 `prototype/data/runs/contract_faults_v1/`。

## 当前边界

本地夹具只验证契约和状态机，不代表任何供应商的实际行为。真实供应商适配器仍需验证部分成交、认证过期、断线重试、重复回报、服务方修订和本地对账恢复。
