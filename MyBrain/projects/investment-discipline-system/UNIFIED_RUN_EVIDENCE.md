# 统一研究运行证据

## 目的

验证历史检验、纸面工作流、追加式账本和复盘不是四个互相断开的示例，而是可以在同一研究运行中形成事件链。

## 已覆盖

- 研究运行开始事件。
- 开发/留出历史检验事件，带策略版本、数据快照、成本假设和无未来信息审计。
- 证据包、建议、人工决定、风险闸门、纸面订单和纸面成交事件。
- 与基准并列的纸面复盘事件。
- 研究运行完成事件和最终账本校验。

## 可复核入口

    python3 -m prototype.run_unified_prototype_case

运行产物位于 `prototype/data/runs/unified_prototype_v1/`：

- `run_result.json`：统一运行的结构化摘要。
- `ledger.jsonl`：从历史检验到复盘的同一追加式事件链。
- `run_report.md`：人工可读边界说明。

## 当前结论

受控夹具和保存的 FRED 来源统一连接都已经通过。它不等于正式投研系统：FRED 价格指数不是正式总回报基准，正式公司行动处理和外部纸面适配器仍未接入。

## 真实来源入口

    python3 -m prototype.run_real_data_unified

运行产物位于 `prototype/data/runs/real_data_unified_v2/`。这个运行把源文件清单、原始内容哈希、决策时点数据快照、历史检验、纸面工作流和复盘写入同一条账本；决策快照不包含事后进入/退出观察。
