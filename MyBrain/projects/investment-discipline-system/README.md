# 投研纪律系统｜项目空间

这是 Javen 与 AI 协作推进“投研纪律系统”的长期项目空间，也是项目的外部记忆入口。

## 这个空间解决什么问题

聊天适合思考、讨论和推进；Obsidian 适合保存经过确认的目标、状态、任务、决定、证据和下一步。每次继续工作时，先读取这里的项目资料，再开始行动，避免因为上下文变化而重新猜测项目方向。

## 文件职责

- PROJECT_CHARTER.md：项目为什么存在、当前范围、非目标和成功标准。
- STATUS.md：当前真实状态；只写已经知道、已经完成和仍然未知的内容。
- TASK_BOARD.md：待启动、进行中和已完成的工作。
- ROADMAP.md：当前阶段、后续阶段和未来扩展，不等于承诺。
- DECISIONS.md：已经确认的决定、理由、状态和待复核点。
- RESEARCH_INDEX.md：调研来源、来源类型、主要结论和证据强度。
- AI_COLLABORATION_METHOD.md：如何使用 AI/Codex 进行可靠的研究、设计、搭建和验证。
- PROJECT_WORK_SYSTEM.md：本项目采用的项目工作系统，以及未来如何抽象成通用能力。

## 协作入口

开始工作前：

- 先读根目录的 AGENTS.md。
- 再读本文件、STATUS.md 和 TASK_BOARD.md。
- 处理具体问题时，只读取相关的决定、调研和计划，避免无关内容污染上下文。
- 先用一句话说明当前状态、目标、可用资料和未知点，再行动。

结束一轮工作时：

- 更新真实状态和任务板。
- 新增或改变长期有效的判断时，记录到决定日志。
- 记录证据、未解决问题和下一步，不把“已经讨论过”写成“已经完成”。
- 如果发现现有规则反复导致错误，先说明证据，再讨论是否修改规则。

## 当前边界

这是一个个人使用的项目空间。系统当前不服务其他用户，不涉及对外发布、多人权限、商业化或自动替他人交易。未来扩展只进入路线图，除非另行确认，不会提前混入当前实现。
