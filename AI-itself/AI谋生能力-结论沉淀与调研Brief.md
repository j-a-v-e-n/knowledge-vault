# AI 谋生能力：结论沉淀与调研 Brief

> 来源：与 Claude 顾问的系列对话（2026-07）。用途：防遗忘的单一事实源。所有结论均经过网上查证。

## 一、核心结论（一句话版）

1. **快变层不学，外包**：具体模型/框架/API 用法 → Context7（MCP，9000+ 库最新文档自动注入）；行业动向 → AI News 等每日 digest。零学习成本。
2. **慢变层重点学**：软件工程基本功、评估与验证（评估器是护城河）、用不可靠组件搭可靠系统、产品判断力、分发能力。
3. **最大盲区是分发**：99% 的 solopreneur 说分发是头号问题；72% 的成功者说决定成败的是分发不是产品。信任来源于对人的了解（build in public），不是产品本身。
4. **主线 = 一个有真实用户的在跑项目**；人物名单提供世界观，项目提供骨架。
5. **验证金字塔**（人只做塔尖）：痛点工具扫抱怨（全自动）→ AI 主持访谈测意愿（近全自动，10-15 个就够，7+ 重复即强信号）→ 预售页测掏钱（全自动，围观 ≠ 掏钱）→ 人亲聊 3-5 个（校准 AI 访谈这把尺子 + 长直觉；AI 访谈员比人类多 49% 附和用户——2026 Science 研究）。
6. **给自己装 harness**：每次尝试前写下预期，结束写一页复盘。解决"成功不知为何成功、失败不知为何晕"。
7. **小赌注纪律**：每个项目时间盒 2 周，到期必须公开发布或写复盘放弃，不许恋战。失败是昂贵的学习方式，所以把每次注下小（Vassallo/Small Bets 哲学）。
8. **每个项目开工前必做竞品扫描**（结构化为 gate，见第三节）。
9. **"预测大厂下一步"策略的正确用法**：不是抢跑大厂路线图，而是站在"模型每次变强你都受益"的位置。判据见第三节五问。

## 三、两道结构化 Gate（加进 AI Architect harness）

### Gate 1：Prior-Art Gate（竞品/前人扫描门）
任何项目 brief 必须包含"已有产品扫描"一节：找到了什么、借鉴哪块、差异点是什么、为什么还值得做。此节缺失或空话 → Architect 不放行开工。

### Gate 2：大厂碾压风险五问（并入 Prior-Art Gate 评分）
判据出处：OpenAI 首席战略官 Jason Kwon 的自述——"在通往通用智能关键路径上的，我们就感兴趣；不在的，我们天然不感兴趣"；以及 2024-2026 AI 创业失败模式分析。

1. **主干道问**：这功能在不在"通往 AGI 的主干道"上（通用能力、水平工具、消费级大市场）？在 → 高危。垂直、琐碎、离 AGI 远（如制造流程类）→ 庇护所。
2. **Wrapper 测试**：如果 API key 明天被切断，产品还活着吗？死 → 你不是产品，是别人的免费分销。（数据：60-70% 的 AI wrapper 收入为零。）
3. **升级方向问**：下一代模型发布，你的产品是变强还是被替代？
4. **护城河问**：有没有实验室拿不到/不想要的东西——垂直数据、行业关系与合规、基于信任的分发、领域评估器？（Harvey 案例：法律判例专有数据 + 多层幻觉检测验证系统 = 评估器护城河的实证。）
5. **预案问**：路线图里有没有"大厂做了这个功能之后我怎么办"的答案？没有 → 不开工。

**配套自动化**：让 Claude Code 的 digest watcher 顺带监控大厂信号（发布会、API changelog、招聘页），路线图动向自动进周报。
