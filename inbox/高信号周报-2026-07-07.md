## Simon Willison

**[sqlite-utils 4.0, now with database schema migrations](https://simonwillison.net/2026/Jul/7/sqlite-utils-4/#atom-entries)** (2026-07-07) — sqlite-utils 发布 4.0,是该项目第 124 个版本、自 2020 年 11 月 3.0 以来首次主版本号升级。三大新特性:数据库 schema migrations(用 Python 文件定义迁移序列,自动追踪已应用/待应用的迁移)、嵌套事务(新的 `db.atomic()` 方法)、复合外键支持。迁移底层用 `table.transform()` 实现 SQLite 官方推荐的 "建临时表→拷数据→删旧表→改名" 模式,绕过 SQLite ALTER TABLE 的限制。值得看:SQLite 生态里轻量级 migration 方案一直缺位,这个工具链补齐后,个人项目用 SQLite 做正经数据管理的门槛又降了一截。
