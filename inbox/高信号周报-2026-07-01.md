**[Autoresearch: The feedback loop behind self-improving agents](https://www.latent.space/p/autoresearch-introspection)** (2026-07-01) — 对 Introspection 联合创始人兼 CEO Roland Gavrilescu 的专访。他与联合创始人 Julian Bright 此前在 xAI 做 agent infrastructure 和 cloud agents，离开后创办 Introspection，为部署"自我改进系统"构建基础设施。他提出 autoresearch 概念：在 agent 外面再包一层"outer loop"，用反馈信号、evals 和人工输入持续维护和改进主系统，并强调自动化软件工厂必须先向人类学习。值得看的原因：它标志着行业焦点正从 agent harness 转向 feedback loop，是 AIEWF 上"loop"主题最系统的表述之一。

## Hamel Husain

**[“It’s Hard to Eval” Is a Product Smell](https://hamel.dev/blog/posts/eval-smell/)** (2026-06-29) — Hamel 三年专注 AI evals，最常听到的反对意见是"我们的产品很难 eval"，他认为这本身是 product smell：你难以验证的产出，用户往往也难以验证，最坏情况下用户得从头重做一遍工作来核对结果。他主张"为易验证性做产品设计"应先于构建 evals，并以他顾问过的三个产品（如 AI data agent 只输出一个答案、无任何可核查产物）给出 before/after 设计草图——正确做法是提供 checkable artifacts。值得看的原因：把 eval 难题从工程问题重新定义为产品设计问题，是 evals 讨论中少见的视角升维。

## AI News 本周要点

**1. 前沿模型进入"受控发布"时代。** 本周两大发布——OpenAI 的 GPT-5.6 Sol/Terra/Luna 仅向受信任伙伴受限预览、并明确披露其未越过 Cyber Critical 阈值；Anthropic 的 Fable/Mythos 5 在与政府协作后重新上线、Sonnet 5 则面向大众全量铺开。能力分级、安全评估和放量节奏正取代"一键全球上线"成为发布标配。（[6/26 期](https://news.smol.ai/issues/26-06-26-gpt-56-preview/)）

**2. 开源模型逼近前沿，且访问方式被产品化。** Z.ai 的 GLM-5.2 在 Code Arena: Frontend 达到 1595 分、超过 Opus 4.8 并逼近 Claude Fable 5，在 PostTrainBench 上以 34.29% 险胜 Opus 4.8 Max 且 84 次运行零失败；同时 Cline 推出 $9.99/月开源模型通行证、Cognition 推出宣称降本 35% 的 Devin Fusion。开源不再只是"差距在缩小"的叙事，而是有 benchmark 数字和商业包装的现实选项。（[6/25 期](https://news.smol.ai/issues/26-06-25-not-much/)、[6/29 期](https://news.smol.ai/issues/26-06-29-not-much/)）

**3. Agent 形态向"随时在线、随处可控"扩展。** Cursor 发布 iOS 应用，支持 always-on cloud agents、手机上远程操控本机 agent 和 diff review；叠加 AIEWF 上 loops 与 software factories 的主题热度，agent 正从 IDE 里的助手变成持续运转、可移动监管的后台工作力。（[6/29 期](https://news.smol.ai/issues/26-06-29-not-much/)）

**4. 内部 token 消耗数据揭示"用量爆炸才刚开始"。** OpenAI 披露内部 Codex 使用数据：2025 年 11 月至 2026 年 6 月，Research 部门 median 输出 token 增长 56 倍、Customer Support 32 倍、Engineering 27 倍、Legal 13 倍——而在 2025 年 8 月前员工平均只把不到 10% 的 token 用于 Codex。连拥有无限额度的内部用户都长期低用 AI，暗示全行业 token 需求的上限远未到来。（[6/25 期](https://news.smol.ai/issues/26-06-25-not-much/)）

**5. AI 向脑机接口与科学纵深渗透。** Meta 的 Brain2Qwerty v2 实现从非侵入式原始脑信号实时解码整句文本，并开源训练代码与数据集，是本周最受技术圈关注的研究进展；结合两大实验室同周发力 AI for Science（Claude Science、GeneBench-Pro），AI 的下一批高价值场景正在编码之外成型。（[6/29 期](https://news.smol.ai/issues/26-06-29-not-much/)）
