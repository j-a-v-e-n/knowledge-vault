## Part B — 勘探环 innovation/prospector/（照 supervisor 模板建）

**位置**：`innovation/prospector/`（提案对象是 innovation 的信号源，复用 `innovation/lib.py` 全套 + config merge，与 supervisor 同构）。

### 第 0 步（§1.7 硬闸，先于一切 checker/coverage 代码）
`innovation/prospector/research/2026-07-10-survey.md`：graded、带源调研——现成 coverage/blind-spot 工具全景（确认无免费可采用 OSS）、NAICS/CBP 数据文件的确切下载与格式、reverse-prospect 候选源（Indie Hackers / Starter Story / Acquire.com 等）逐个 RSS 可用性 + ToS 合规结论、"has-phone-no-website" 类结构化缺口检测的现成做法（OSM 等）。**这份不落盘，一行 coverage 代码不写。**

### 文件布局（镜像 supervisor）
- `CHARTER.md`（冻结，sha 记入每份周报）：owner 命令里的职责 (a)(b)(c)(d) 逐字誊入 + 纪律：observe+propose only、证据分级（查到的/推断的分开标）、ToS 合规红线（Facebook 群组等不可爬的明确排除）、**唯一写例外**（见下）。
- `config.toml`（merge over innovation 的）：models、timeouts、`top_blind_spots=3`、web-research 轮次预算。
- `lib.py`：抄 supervisor 的 `assert_writable()` 写禁区 + `write_text`（vault_call 30s 超时）+ `commit_run`。
- `data/`：一次性落盘的版本化数据——NAICS 2022 结构表（转 CSV，记来源 URL+sha）、CBP US 级各 3-digit NAICS 年薪资/机构数（"钱在哪"权重，年更数据无需每周拉网）。
- `taxonomy.py` + `coverage.py`：覆盖地图 = `coverage/map.json`（~100 个 3-digit NAICS 段 × 现有信号源）。每段：money_weight（CBP 薪资额）、audibility（聋/半聋/可听——证据 = 哪些 feed 结构上够得着 + 近期已摄入信号经 LLM 映射到段的实际分布）、rank = money × deafness。周报只报 **delta**。
- `research.py`：对 top-3 盲区做 web-enabled 调研（`claude_cli.call(..., allowed_tools=["WebSearch","WebFetch"], max_turns=预算)`，先例 commercial/lib.py:154）——那群人的痛在哪冒头 → 候选源提案；候选 RSS 一律过 `supervisor/feeds.py::probe_feed` 机械验活 + 每条记 ToS 结论。
- `reverse.py`：反向勘探——从公开"谁在挣钱"信号（第 0 步调研定下的可用源）反推其变现的是谁的痛 → 标回地图段。
- `pipeline.py`：周跑 COVERAGE → BLINDSPOTS(top-3) → RESEARCH → REVERSE → CARD → commit。charter sha fail-closed、`window_open()` + `wait_for_monday_train()` 守卫、每 stage 过 `lib.ingest`（⑧ 机械接线）、runs/<date>/ 留档。
- `watch.py`（30 分钟 rider，抄 supervisor/craft）：收 owner 一词裁决；**唯一写例外**——owner 批准的加源提案，由 rider 机械应用到 `innovation/config.toml` 的 `[[pain_feeds]]/[[idea_feeds]]`（先 probe_feed 验活、先备份、带 rollback、全程 log），照 supervisor 死源修复的同一纪律。未批准的一律不动。
- `tests/test_offline.py`：写禁区、taxonomy 加载、coverage 数学、卡片渲染、断网可跑。

### 周交付（照 supervisor 路由规则）
`勘探周报-<date>.md`：coverage map delta + 盲区 top-3 + 具体加源提案（每条带证据分级 + ToS 结论 + probe 结果）+ 本环自己的 ⓪ 溯源行。有提案 → `0-工作台`（`**需要你做什么**` 头 + pending 回执给 watch.py）；空周 → inbox。同时 runs/ 留档。
