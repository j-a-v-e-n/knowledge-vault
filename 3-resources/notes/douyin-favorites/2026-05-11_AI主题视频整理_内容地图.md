## 主线观察：8 个视频指向同一个故事

读完这 8 个视频，浮现出一个**贯穿性叙事**：

> **2026 年的 AI 工具正在经历三重转变**：
> 1. **终端工具 → Agent 平台**（Claude Code、DeepSeek TUI、CodeBanana）
> 2. **API 依赖 → 本地推理**（Antirez 项目，DeepSeek 开源权重 + 推理引擎）
> 3. **个人助手 → 团队协作**（CodeBanana 把 agent 拉进多人项目，SEQUENCE OS 强调 "long-term existence"）

每个视频是这个大叙事的一个截面：
- **A1/A2** 讲 Claude Code 的 agent 化（自动权限、工作树、cron 触发器）
- **B1/B2** 讲 DeepSeek 生态如何**让 agent 平价化 + 本地化**
- **C1** 讲这种转变制造的**新岗位**（AI 落地咨询师）
- **C2/C3** 讲一个人借助 AI 工具能做出**系统级产品** + **专业级 PPT** 的新生产力
- **D1** 讲 agent 进入团队后**组织结构**怎么变
