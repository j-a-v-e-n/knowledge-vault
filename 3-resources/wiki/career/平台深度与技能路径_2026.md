## 1. Top contractor 平台（高时薪）

### 1.1 Mercor — 推荐 #1

#### 是什么

✅ Mercor 是专为 AI 公司（OpenAI, Anthropic, Scale AI 等）招"按需 ML/AI 人才"的市场。AI 公司发任务（"帮我们写 LLM eval pipeline" / "给我 RL 训练环境数据"），Mercor 匹配 contractor 远程做。区别于 Upwork：Mercor 客户全是 AI/ML 公司，质量门槛高，时薪也高。

#### 怎么运作（verified from talent.docs.mercor.com）

1. ✅ 选一个 listing → 点 "Apply Now"
2. ✅ 上传简历 → profile 永久存留供未来 apply
3. ✅ 完成 assessment（"written or multiple-choice questions" + "AI Interview"，要 Chrome + camera + mic + screen sharing）
4. ✅ Mercor 内部 sourcing team review → 通过后 match project
5. ✅ 装 Insightful 时间追踪工具 → 接 project → 工作 → 周付

#### 真实薪资

⚠️ Glassdoor: ML 类 contractor avg **$85/hr**，range $50-150/hr，top $200/hr。Onboarding 后 typical 30-40 hr/wk（不保证每周满）。

#### Skill 门槛（你需要具备什么）

⚠️ Mercor 官方：minimum "undergraduate-level expertise"，preferred "graduate student / master's / PhD candidate in relevant domain"。

具体要会的（基于 Mercor LLM/RL 任务类型）：
- **Python + PyTorch** — 实战必备（你 ECE 175B/284 已经做过）
- **LLM 知识** — Transformer 架构 / fine-tuning / prompt engineering / eval（你 ECE 284 做过 Med-HALT 评估 ✓ 直接对口）
- **RL 知识** — PPO / RLHF / reward modeling（你目前缺，但项目都不强制要）
- **工程能力** — 写干净的 Python 代码 / Git / 调试 / docstring
- **沟通** — 流畅英语 written + AI interview 答得清

#### Javen 当前 gap 分析

基于 [[career/resume-master]]：
- ✅ 已具备：PyTorch / LLM eval / Computer Vision / Robotics
- ⚠️ 弱项：RL（PPO/RLHF 没系统学过）— 不阻塞 apply，但拿 RL 项目时要补
- ⚠️ 弱项：production-grade 代码 vs 学术 prototype 代码 — Mercor 客户期望前者

#### 推荐立刻做

1. mercor.com 注册（不要拖；onboarding 3-4 周吃掉 dispatch 时间）
2. 简历突出 ECE 175B (Diffusion) + ECE 284 (LLM eval) — 这两个最 fit Mercor 任务池
3. 准备好 GitHub 公开 repo（即使是 student project 也行，但要有 README + 干净 commit history）

### 1.2 Toptal — 推荐 #2（但有 risk）

#### 是什么

✅ Toptal 自称 "top 3% freelance network"。任何 freelancer 申请要过 5 阶段筛选，通过率 < 3%（200,000+ 年申请者）。通过后进 "talent pool"，client 通过 Toptal 找你，时薪 $80-200/hr。

#### 怎么运作（verified from toptal.com top-3-percent）

5 阶段 screening：

1. ✅ **English language + communication evaluation** — 测英语 + personality fit（"passionate and fully engaged"）
2. ✅ **Technical knowledge + problem-solving** — 题库测试（"exceptional results" 才过）
3. ✅ **Expert interview / live coding** — Toptal 内部 ML expert 给你 live 出题，看 "problem-solving ability, depth of experience, communication, creativity"
4. ✅ **Test project** — 1-3 周的 real-world project，做完交付
5. 💡 第 5 阶段（screen call / final review）—文献多次提及但我没 verified 具体名字

⚠️ 整个流程 3-8 周。⚠️ **如果失败，6 个月 cooldown 不能再申请**。

#### 真实薪资

⚠️ Levels.fyi / Arc.dev: senior ML $80-150/hr，AI/ML lead $120-200/hr。

#### Skill 门槛（你需要具备什么）

具体要会的：
- **算法 + 数据结构** — live coding 阶段是 LeetCode medium-hard 风格（💡 我的训练知识，待 verify）。这是你最可能的 gap
- **ML 深度** — 不只 PyTorch API，要懂 transformer 推导、optimization 原理、能 explain why
- **System design** — senior 级别问 "design 一个 distributed inference system"
- **流畅英语** — 第 1 阶段就筛
- **3-5 年实战经验** ⚠️ — 这是 Toptal 历史画像（你大四 senior 可能被认为经验不够）

#### Javen 当前 gap 分析

- ✅ 已具备：ML 深度（ECE 175B/284）
- ❌ 缺：算法 LeetCode 训练量（如果你没刷过 NeetCode 150 这种）
- ❌ 缺：3-5 年工业实战经验
- ⚠️ 风险：失败 6 个月 cooldown

**owner mindset 判断**：Toptal application 时间投入大（2-3 周准备 + 几周 screening），失败 cooldown 6 个月。**不建议你 summer 主攻 Toptal**，除非你算法基础已经很强。可以**先 apply Mercor 拿到现金流再考虑 Toptal**。

### 1.3 Outlier (Scale AI 子品牌)

#### 是什么

⚠️ Scale AI 旗下，给 OpenAI/Anthropic 等大模型公司提供训练数据的人类标注/编程任务。Outlier 上 contractor 做的事：(a) 写 coding 任务给 LLM 学 (b) Review LLM 生成的代码标对错 (c) 解释复杂概念给 model fine-tuning。

#### 怎么运作（verified from third-party reviews）

⚠️ 30-90 分钟 onboarding：(1) 注册账号 (2) 选 expertise areas (3) 做 skill screening (4) ID verification → 通过后接 task。

#### 真实薪资

⚠️ Coding expert US：**$40-60/hr**（senior 偶尔 $60-100）。Generalist writing $15-25 不要做。AI reviewer $65/hr。周二付款。

#### Skill 门槛（你需要具备什么）

- **Python / JavaScript 编程** — 必须能写正确代码
- **能用流畅英语 explain 代码** — Outlier 任务核心是"教 AI 学 coding"，所以你写的注释、解释要清楚
- **debug 能力** — 经常要 review LLM 写的代码，找 bug
- **本科学位 minimum，preferred master/PhD candidate** ⚠️
- 英文 fluency 必须

#### Javen 当前 gap 分析

- ✅ 已具备所有 — 你 ECE senior + Python + 英语流利 + ECE 项目经验
- **0 学习成本，直接 apply**

#### 推荐立刻做

1. outlier.ai/expert 注册
2. expertise areas 选 "Coding"（不要选 Writing，时薪太低）
3. 30-90 min 做完 skill screening
4. 等 task assignment

### 1.4 Codementor

#### 是什么

✅ 1-on-1 在线 mentor 平台。Mentee 付钱（按小时 / 按 session）请 mentor 帮 debug / 教概念 / review code。AI/ML 类 mentor 时薪 $80-250/hr 自由定。

#### 怎么运作（verified from third-party + codementor.io）

⚠️ 1-2 周审 application。审通过后你的 profile 上线，client 主动找你或你接 listed projects。

#### Skill 门槛（你需要具备什么）

- **教学表达能力** — 能把复杂概念讲清（你 ECE 课程中如果做过 TA / SI / tutoring 这种就有优势）
- **portfolio + GitHub 公开 repo** — client 看你做过什么
- **流畅英语**
- **耐心 + 接得住"教学"角色**

#### Javen 当前 gap 分析

- ✅ 已具备技能门槛
- ⚠️ 弱项：可能没 explicit "教学经验"。如果你做过 ECE 课程的 office hours / 帮同学 debug — 写进 profile 增强信号
- **几乎 0 学习成本，profile 写好就行**

#### 推荐立刻做

1. codementor.io/mentor/apply 注册
2. profile 重点：(a) 列 ECE 175B/284/148 项目 (b) GitHub link (c) 写 1-2 段 "I can help with: PyTorch debugging / LLM eval setup / Computer Vision pipelines"
3. 定价：从 $80/hr 起（senior ECE 不要低于这个；client 觉得太便宜反而怀疑 quality）

## 2. Competition 平台

### 2.1 Kaggle

#### 是什么

✅ ML 竞赛 + dataset + notebook 三合一社区。AI 公司 / 大学 / 政府 post competition，奖金 $500-$1M，参赛者按 leaderboard 排名拿奖。

#### Ranking 系统（💡 我的训练知识 — 建议 user verify from kaggle.com/progression）

5 个等级（per track：Competitions / Datasets / Notebooks / Discussion）：
- **Novice**: 注册即是
- **Contributor**: 完成 profile + 至少 1 个提交 + 1 个 comment + 1 个 upvote
- **Expert**: Competitions track = 2 个 bronze medal（每 medal 来自 top 40%/20%/10% of leaderboard 不同等级）
- **Master**: 1 gold + 2 silver
- **Grandmaster**: 5 gold + 1 solo gold

Medal 是 ranking 系统的核心；简历上写 "Kaggle Expert" / "Master" 是 ML 招聘强信号。

#### Skill 门槛（你需要具备什么）

具体要会的：
- **Pandas + NumPy + scikit-learn** — tabular competition 基础
- **PyTorch / TensorFlow** — deep learning competition
- **数据 EDA + feature engineering** — 经典 tabular competition 80% 决胜在 feature
- **集成 (ensemble)** — XGBoost + LightGBM + neural net stack
- **GPU 使用** — Kaggle 免费 T4，30 hr/wk
- **领域知识** — medical imaging / time series / NLP 各自有专属技巧

#### Javen 当前 gap 分析

- ✅ 已具备：PyTorch / 神经网络 / Python 数据处理
- ⚠️ 弱项：Pandas/EDA 流畅度（你做学术更多直接 PyTorch，没怎么折腾 tabular feature engineering）
- ⚠️ 弱项：Kaggle 特有 trick（test data leak / public LB vs private LB 策略 / ensemble 黑魔法）

#### 推荐学习路径

不要先学再做。**直接选 1 个 active competition 开干，边做边补**。推荐流程：
1. kaggle.com 注册
2. 看当前 active "Featured" competition（奖金高的）→ 选 1 个领域跟你 ECE 项目接近的（医疗影像 → fit 你 PPG / NN, 时间序列 → fit 你 175B time series 经验）
3. 看 top kernel / public notebook → fork 一个 baseline → 改进
4. 跟 discussion forum 学 trick
5. **预期**：第 1 次 competition 进 top 50% 就好；2-3 次后进 top 20% 拿 bronze 进入 Expert tier

### 2.2 Hackathon (Devpost / Lablab.ai / MLH)

#### 是什么

✅ 周末 (24-72 小时) build demo 比赛。组队或单飞。评委评 demo + idea + execution。

**3 大平台区别**：
- **MLH (mlh.io)** — 大学生为主，prize $1k-$10k typical，event 多
- **Devpost (devpost.com)** — online hackathon 主，奖金 $5k-$50k，大公司赞助多（Microsoft / OpenAI / Cohere）
- **Lablab.ai (lablab.ai)** — AI-only hackathon，每月好几个，奖金 $1k-$30k，Anthropic/OpenAI/Mistral 经常做赞助

#### Skill 门槛（你需要具备什么）

具体要会的：
- **快速 prototype** — 48 小时内 build 一个 demo，技术栈选择重要
- **LLM API 集成** — OpenAI / Anthropic / HF Inference API call
- **Frontend basic** — Streamlit / Gradio / Next.js 起码会一个
- **Pitch 演示** — 5 min demo video / live presentation
- **GitHub README 写**

#### Javen 当前 gap 分析

- ✅ 已具备：Python / LLM 集成 / Backend logic
- ⚠️ 弱项：可能没用过 Gradio / Streamlit / Next.js（Frontend / demo skin）
- ⚠️ 弱项：pitch 能力（学术 presentation ≠ hackathon pitch）

#### 推荐学习

- Gradio quickstart: gradio.app 文档，2 小时熟
- Streamlit quickstart: streamlit.io 文档，2 小时熟
- 看 Devpost 上几个 winning project 的 demo video，学 pitch 节奏（5 min 结构：problem → solution → demo → impact）

#### Javen 当前 gap 分析

- ✅ 已具备所有

## 5. 关键判断框架

**"我要不要为某 platform 学某 skill？"** — 看 ROI：

| Platform | 当前 fit? | 学习 ROI |
|---|---|---|
| Mercor | ✅ 直接 apply | 不用学；apply 通过率高 |
| Outlier | ✅ 直接 apply | 不用学；apply 通过率高 |
| Codementor | ✅ profile 即可 | 不用学；写好 profile |
| Kaggle | ✅ 直接做 | 实战中学，不是先学再做 |
| Hackathon | ✅ 直接做 | 学 Gradio 2 小时即可 |
| Algora | ✅ 直接做 | 实战中学 |
| **Toptal** | ⚠️ 算法 gap | 学 200-400 小时 = ROI 低；**不推荐 summer 主攻** |

**结论**：**90% 你不需要"先学再赚"**。Mercor + Outlier + Codementor + Kaggle + Hackathon + Algora 全部"直接动手 + 边做边学"。只有 Toptal 是"先大量学算法才可能通过"，因此 summer 不推荐。

**最重要的 1 句话**：**Mercor 是你 summer 优先级 #1**。你已经够格，3-4 周 onboarding 通过后开始拿 $85/hr 项目。其他都是补充。
