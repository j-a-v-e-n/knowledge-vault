  # Method A: TROIKA-lite Summary
2026-05-20

## 设计思路

Method A 是 paradigm benchmark 的信号处理基线，不追求 SOTA，而是为 method C 提供同一 pipeline 下的对比起点。

Pipeline: PPG bandpass → FFT → coef-normalized spectral subtraction → HR tracking peak selection → BPM

## 关键决策

**1. coef normalization**

Sanity 发现 PPG/accel PSD scale 差 1500×，λ=1.0 时 spectral subtraction 等于 no-op。改用 HR 频段内最小二乘回归得到 coupling coefficient，缩放后再减。Subject 01 MAE: 24.6 → 20.9。

**2. HR tracking + cold start + self-correction**

发现 cleaned 频谱内多个能量相近 peak，max-peak selection 对噪声敏感。引入上一窗 HR 约束 (±15 BPM)，加 cold start (前 N 窗不约束) 和 self-correction (band 内峰 < global max × T 时 fallback)。Subject 01 MAE: 20.9 → 13.6。

## 简化部分

按 proposal §4 砍掉 M-FOCUSS + 双通道融合。理由: controlled comparison 要求 method A/B/C 共享 pipeline，M-FOCUSS 实现门槛超出本科课程时间预算。

## 结果

Overall MAE: **15.11 BPM** (11 subjects, subj09 在 Udacity 镜像缺失)
- 6 subjects < 10 BPM
- 3 subjects 13-17 BPM
- 2 catastrophic outliers: subj02 (31), subj10 (59)

参数 N=10, T=0.5, J=15, λ=1.0

## 留给 method C 的研究空间

Method A 两类失败:
1. **Peak ambiguity** – cleaned 频谱多峰，max selection 选错
2. **Tracking lock-in** – cold start 后锁错 basin 救不回 (subj02, subj10)

Method C 测试 LLM 能否:
- 看频谱多峰 + HR history 选对
- 调 λ 间接 rescue lock-in 窗口

这是 paradigm-level 对比 (LLM 推理 vs explicit state space)，不是精度竞赛。






# Method B: Random Forest Baseline Summary
2026-05-20

## 设计思路

Method B 是 paradigm benchmark 的 supervised ML baseline，与 method A (signal processing) 对照。同一 11-subject LOSO setup，相同 8 秒窗口切分。

Pipeline: 信号 → 特征提取 (11 维) → RF 训练 (LOSO 每折训练 1 次) → HR 预测

## 关键决策

**1. 特征选择**

11 个特征覆盖三类:
- PPG 频域 (4): dom freq/power, band energy, peak-to-band ratio
- Accel (5): dom freq/power, band energy, magnitude mean/variance  
- Cross (2): ppg/accel peak ratio, freq diff

特征来自 proposal §4，全部 frequency-domain。**不做特征选择 / PCA**——controlled comparison 不调 RF 这一块。

**2. 模型固定参数**

`RandomForestRegressor(n_estimators=100, random_state=42)`，无超参 tuning。理由同 method A: 不是 RF 调优研究，是 paradigm comparison。

## 结果

Overall MAE: **11.14 BPM** (11 subjects)
比 method A (15.11) 好 3.96 BPM

| | 低 motion subjects | 高 motion subjects | Outlier |
|---|---|---|---|
| **A 赢的 subject** | subj05/06/08/12 (MAE 1.9-6.3) | – | – |
| **B 赢的 subject** | – | subj01-04/11 | subj02 (31→13), subj10 (59→27) |

**关键观察**: B 没有 catastrophic outlier (最差 27 BPM)，A 有 (subj10 = 59)。

## A vs B 的分裂模式

- **低 motion / 稳定 HR**: A 赢。signal processing 的物理原理性优势 RF 学不到
- **高 motion / tracking failure**: B 赢。RF 没有 sequential dependency，不受 lock-in 影响

## 留给 method C 的研究空间

A 和 B 各擅长一类场景。Method C 的真正问题不再是"打过 fixed λ"，而是:

> LLM 能否 per-window 决定 λ，使 pipeline 在低 motion 时表现像 A、在高 motion 时不像 A 那样 tracking lock-in?

这是 method C 的 **paradigm-level differentiation**——不是单一指标对比，是适应性 (adaptiveness) 的研究问题。
