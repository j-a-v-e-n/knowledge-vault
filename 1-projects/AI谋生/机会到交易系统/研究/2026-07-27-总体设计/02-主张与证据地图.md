# 主张与证据地图

状态说明：

- 事实：来源直接支持，仍受其样本、方法、年代和情境限制。
- 综合推断：由多个来源共同推出，不是任何单篇论文的原句。
- 设计选择：为了让系统可审计、可证伪和可控而作出的工程决定。
- 未知：必须由未来具体市场和真实交易实验回答。

## 核心主张

| 主张 | 类型 | 支持证据 | 反证或边界 | 对设计的含义 |
|---|---|---|---|---|
| 商业不能只看“有没有需求”，还必须同时解决价值创造、价值交付和价值捕获 | 事实加综合推断 | [Teece：Business Models, Business Strategy and Innovation](https://doi.org/10.1016/j.lrp.2009.07.003) | 同一价值在不同买家、渠道、时点和成本结构下可能不是机会 | 机会必须通过买家、触达、支付、交付和单位经济的合取门 |
| 机会既可能被发现，也可能在行动中被共同创造 | 事实 | [Alvarez 与 Barney：Discovery and Creation](https://doi.org/10.1002/sej.4)；[Sarasvathy：Causation and Effectuation](https://doi.org/10.5465/amr.2001.4378020) | “创造”不等于可以任意操控欲望，也不能跳过真实行为验证 | 系统同时容纳观察型发现与 Demo、试用、共创型实验 |
| 明示需求与隐性需求都重要 | 事实 | [Narver、Slater、MacLachlan：Responsive and Proactive Market Orientation](https://doi.org/10.1111/j.0737-6782.2004.00086.x) | 隐性需求不是模型读心；只能从行为、处境和干预结果推断 | 保存需求解释及竞争解释，并寻找可区分它们的实验 |
| 用户生成内容可以帮助识别需求 | 事实 | [Timoshenko 与 Hauser：Identifying Customer Needs from UGC](https://doi.org/10.1287/mksc.2018.1123)；[Needmining](https://arxiv.org/abs/2003.05917) | 研究支持“发现材料”，不支持支付意愿和总体市场规模 | 网络信号只能生成调查候选，不能自动晋级为商机 |
| 投诉、评论和社区发言存在自选择与平台偏差 | 事实 | [Raval：Consumer Complaining Behavior](https://doi.org/10.1287/mksc.2018.1140)；[社交媒体数据偏差综述](https://doi.org/10.1016/j.ijmedinf.2022.104804)；[在线评论选择偏差](https://aisel.aisnet.org/misq/vol41/iss2/8/) | 某些平台或经过校正的数据仍可有预测价值 | 每条观察绑定平台、入口、时间、群体边界、分母和去重方式 |
| 隐性需求常从真实工作、绕行和自制工具中暴露 | 事实 | [Empathic Design](https://hbr.org/1997/11/spark-innovation-through-empathic-design)；[Lead User Theory](https://doi.org/10.1287/mnsc.32.7.791) | 绕行证明任务值得投入，不证明愿意切换或付款 | 现实通道不能只抓文本，还要寻找表格、脚本、外包、重复劳动和已有支出 |
| 新方案的体验可能使偏好显现或被构造 | 事实 | [Bettman、Luce、Payne：Constructive Consumer Choice](https://doi.org/10.1086/209535)；[Slovic：The Construction of Preference](https://doi.org/10.1037/0003-066X.50.5.364)；[Virtual Product Experience](https://doi.org/10.1016/j.technovation.2006.09.005) | Demo 反应依赖呈现、文案、选项和价格，未必稳定 | 单设“方案唤醒的需求”，完整记录干预，不伪装成自然需求 |
| 口头购买意向与假设性支付意愿不能替代真实购买 | 事实 | [Morwitz、Steckel、Gupta](https://doi.org/10.1016/j.ijforecast.2007.05.015)；[Webb 与 Sheeran](https://pubmed.ncbi.nlm.nih.gov/16536643/)；[消费品假设性支付意愿元分析](https://doi.org/10.1007/s11747-019-00666-6) | 意向在部分产品与短期情境中仍有预测价值 | 证据逐级升级到时间、数据、引荐、正式报价、订金、付款和复购 |
| 购买取决于相对净价值，不只是功能质量 | 事实加综合推断 | [Zeithaml：Price, Quality and Value](https://doi.org/10.2307/1251446)；[Customer Perceived Value 元分析](https://doi.org/10.1177/10946705231222295)；[Switching Costs Typology](https://doi.org/10.1177/0092070302250897) | 价值的构成和权重随场景变化，没有跨行业万能公式 | 每个候选记录现状、价格、时间、学习、迁移、风险、信任与“不行动” |
| B2B 中使用者、受益者、付款者和批准者可能不同 | 事实 | [Webster 与 Wind：Organizational Buying Behavior](https://doi.org/10.1177/002224297203600204) | 小型个人交易中角色可以重合 | 利益相关者与采购路径是独立 Gate |
| 满意、实际结果、复购与锁定不是同一件事 | 事实 | [Oliver：Satisfaction Decisions](https://doi.org/10.1177/002224378001700405)；[Mittal 与 Kamakura](https://doi.org/10.1509/jmkr.38.1.131.18832)；[Switching Costs 元分析](https://doi.org/10.1016/j.ijresmar.2015.01.001) | 复购仍是有价值的外部行为信号 | 分别记录使用、目标结果、投诉、退款、主动续费、推荐与切换成本 |
| 预先写假设、预测和停止条件能提高早期机会搜索纪律 | 事实 | [Camuffo 等：A Scientific Approach to Entrepreneurial Decision Making](https://doi.org/10.1287/mnsc.2018.3249)；[多项试验复现](https://doi.org/10.1002/smj.3580) | 不支持任何固定 MVP 模板，也不消除错误实验造成的假阴性 | 每次实验前冻结判据，结果后不得改写成功标准 |
| 早期用户可能系统性误导产品判断 | 事实 | [Sampling Bias in Entrepreneurial Experiments](https://www.nber.org/papers/w28882)；[Harbingers of Failure](https://papers.ssrn.com/sol3/papers.cfm?abstract_id=2420600) | Lead user 对发现未来方向仍可能很有价值 | 用极端用户发现，用目标市场样本验证；不能合并为同一证据 |
| Harness、工具、状态、评测和运行时会实质改变 Agent 表现 | 事实 | [OpenAI：Trustworthy Third-Party Evaluations](https://openai.com/index/trustworthy-third-party-evaluations-foundations/)；[LangChain 与 NVIDIA 联合发布](https://www.langchain.com/blog/langchain-and-nvidia-launch-the-nemoclaw-deep-agents-blueprint) | 厂商结果只能支持其配置和评测，不能直接外推到赚钱能力 | 能力声明必须绑定模型、Harness、工具、预算、任务集和评分 |
| 当前 Agent 擅长较可验证的数字任务，但开放世界商业判断仍弱 | 事实 | [METR Frontier Risk Report](https://metr.org/blog/2026-05-19-frontier-risk-report/)；[SWE-Lancer](https://openai.com/index/swe-lancer/) | 快速进步和更好的专用 Harness 可能改变边界，现状不是永久定理 | 先自动化内部、可逆、可验证环节；外部责任动作逐步放权 |
| 当前没有证据支持无人监督的通用“机会到持续盈利”Agent | 事实加未知 | METR 报告记录的开放式赚钱实验、真实工作基准与现有官方 Agent 安全建议 | 现有实验样本和 Harness 有限，不能证明永远做不到 | 完全自治是待分模块验证的远期假说，不是第一版前提 |
| 开放网络输入与高权限动作结合会形成提示注入和数据泄露风险 | 事实 | [OpenAI：Designing Agents to Resist Prompt Injection](https://openai.com/index/designing-agents-to-resist-prompt-injection/)；[OpenAI Agent Safety](https://developers.openai.com/api/docs/guides/agent-builder-safety)；[NIST AI RMF](https://airc.nist.gov/airmf-resources/airmf/5-sec-core/) | 结构化输出、隔离和审批能降风险，但不能保证为零 | 研究环境与邮箱、客户数据、部署、支付环境必须隔离并最小权限 |
| 多 Agent 并不天然优于单 Agent | 事实与设计选择 | [OpenAI Orchestration](https://developers.openai.com/api/docs/guides/agents/orchestration)；[Anthropic Multi-Agent Research](https://www.anthropic.com/engineering/multi-agent-research-system) | 并行搜索、独立挑战和权限隔离确实适合专用多 Agent | 单管理 Agent 为默认；只有合同、工具、政策或独立性变化才拆分 |

## 关键否定结论

以下等式在本轮研究中均不成立：

- 抱怨多 = 市场大
- 搜索上涨 = 愿意付款
- Demo 被称赞 = 需求成立
- 一次付款 = 可复制业务
- 能做出来 = 能卖出去
- 收入大于生成成本 = 单位经济成立
- Agent 说完成 = 环境中真的完成
- Benchmark 高分 = 开放世界可靠
- Harness 有价值 = 该 Harness 本身能找到需求
- AI 能完成多数劳动 = 人可以立即只留下银行账户

## 仍属未知

- 哪个行业、国家、买家类型和渠道最适合作为首个 Pilot；
- 用户目前可利用的信誉、身份、网络和触达资产；
- 某个具体机会的真实价格、响应、交付成本、退款与复购；
- 不同平台抓取、外联、隐私、税务、合同和消费者保护的完整规则；
- 总体系统在真实环境中的精确成功率；
- 各环节最终能升级到多高的自治等级。

这些未知不能靠继续抽象推理消除，必须在用户批准下一阶段后用影子运行和真实、小规模、可逆实验回答。
