# 点子投递箱 — 使用说明

把一个想法写成**一个 .md 文件**丢进这个文件夹即可(自由段落就行,不用格式;文件名随意,首行 `# 标题` 会被用作点子名)。

**之后会发生什么:**
1. 创新闭环每天 09:30 扫这里,把新文件结构化成一等候选(origin=owner),原文逐字冻结存档。
2. **无免检**:你的点子和机器生成的候选过**同一道闸**(C1-C6 代码检查 + A-D 对抗裁决),会被如实杀掉并给理由——这正是投递的意义:拿到一份认真的对抗性裁决。
3. 信封路由照旧:一夜可证伪 → v2 brief;超信封 → killlist 标 exceeds-envelope(= 商业探针候选单)。
4. 处理完的原件自动挪进 `processed/`(不会重复摄取);裁决结果在当日 `inbox/创新闭环报告-*.md` 的"Owner 投递箱"一节。

**注意:** 这个 README 本身不会被摄取;想撤回一个还没被处理的点子,直接删文件即可。
